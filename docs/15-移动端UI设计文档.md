## 1. 定位与设计原则

> 移动端 = **随身的练习场与复习站**：单手可达、一屏一事、反馈即时、误触免疫。
> 大屏（Web）负责深度（图谱全景、多解对比大画布），移动端负责**高频短时**：每日一练、错题重练、打卡、通勤深钻。

| 原则 | 落地 |
|------|------|
| 单手可达 | 主操作位于屏幕下 1/3（Tab、答题卡、提交、打卡）；顶部只放返回与信息 |
| 一屏一事 | 每屏一个主任务；长内容分步（测评 3 步进度、计划确认分卡） |
| 即时反馈 | 判分振动 + 颜色 + 图标三通道（不单靠颜色，a11y） |
| 防误触/防丢失 | 作答退出确认、草稿本地持久、危险操作（注销）二次验证 |
| 数学可用性 | 数学输入工具条常驻、公式 KaTeX、长按题干出公式卡 |
| 多端一致 | 组件语义与 Web 同源（05 §5 tokens），形态按端适配（抽屉 vs 侧栏） |

## 3. 导航架构（M1 + 三件套 + 悬浮球）

```
┌────────────── 手机屏 ──────────────┐
│ NavBar（栈页：返回+标题+右位）        │
│                                    │
│   页面内容（Push / Tab 页）          │
│                                    │
│  [AI 悬浮球 M5]  ← 题面内 [AI] 按钮  │
│ ┌──────────────────────────────┐   │
│ │ 底部 Sheet（答题卡/筛选/协议）  │40%│←→90% 两态拖拽   │
│ └──────────────────────────────┘   │
│ TabBar ×5（仅 Tab 页）              │
└────────────────────────────────────┘
```

| 模式 | 承载 | 规则 |
|------|------|------|
| **Push 栈** | 课时、作答、深钻、测评、报告、设置、详情类 | 自绘 NavBar 返回 + iOS 侧滑手势；栈深上限 8，深链直达清栈 |
| **底部 Sheet** | 答题卡（40/90 两态）、筛选、快捷操作、协议全文、题面 AI（60%） | 抓手条 64rpx 宽；下滑关闭；蒙层点击关闭（作答中答题卡除外） |
| **全屏模态** | 搜索页、AI 对话（悬浮球唤起） | 独立栈，关闭回原位 |
| **Tab** | M1 五页 | 切换保滚动位置与状态；重复点击回顶部 |
| **悬浮球** | AI（M5） | 可拖拽吸边；作答页按BR-03能力决定显示；限辅助隐藏并拒绝接口，学习模式缩小避让 |
