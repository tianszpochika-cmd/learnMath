## 0. 设计决策（AD1-AD5）

| # | 决策 | 结论 |
|---|------|------|
| AD1 | 框架 | **Element Plus 2.14.4** + 05 §1.2 骨架（左侧菜单可折叠 + 顶栏面包屑/用户）；`--el-color-primary: #2F6BFF`；**密度 compact**、表格 13px |
| AD2 | 列表页统一模板 | **「查询栏(筛选chips+关键词) + 表格 + 分页 + 操作列」**；详情与编辑优先用 **右侧 Drawer**（保上下文），复杂编辑才进独立页 |
| AD3 | **路径编排器** | **三栏**：左=节点素材库（可引用类型 list）｜中=编排画布（列式节点卡+顺序拖拽+连线）｜右=属性面板（ref 配置 + **UnlockRuleForm DSL 表单化** + P6 坐标）；顶=保存/schema 校验状态条 |
| AD4 | **推理链编辑器** | **三栏**：左=步骤卡列表（拖拽排序/增删/type 徽标）｜中=**四要素表单**（content / warrant+图谱挂点搜索 / motive / off_ramp + 依赖步多选）｜右=**链缩略预览**（纵向 DAG + 孤步/断链校验提示）；底=quality 状态（curated↔ai_draft）与[提交校对] |
| AD5 | 图谱边编辑 | **全宽画布**（搜索定位 + 一跳邻域高亮）+ 加边交互：点 from → 悬停候选 to → 确认 → **即时无环校验**（成环 3310 红色回显成环路径） |

## 1. 定位

> 管理端 = **内容生产线的控制台**：信息密度优先、键盘友好、一切危险操作可见可撤。
> 三个无先例的自研界面（AD3/AD4/AD5）是本稿核心；其余页面遵循 AD1/AD2 模板化产出。

## 5. 交互规范（管理端）

| 场景 | 规格 |
|------|------|
| 列表通用 | 查询回车即搜；筛选 chips 可单删；行 hover 出操作列；批量勾选条 |
| 抽屉编辑 | Drawer 关闭前有未保存→确认；保存成功→表格行高亮刷新 |
| 拖拽 | 树/步骤/组卷/专题 全部 sortable，拖拽手柄 `⋮⋮`，落位 toast+可撤销 5s |
| 危险操作 | 删除/驳回/禁用/发布协议 = Popconfirm；**审计提示**"操作已记入日志" |
| 富文本 | TipTap + KaTeX 快捷钮；粘贴净化；上传图走 /upload |
| 画布（A04/A11） | 网格吸附；缩放 ctrl+滚轮；框选；**校验不通过禁发布**（灯=红） |
| 表单校验 | 即时+提交双校验；DSL/JSON 编辑器带 schema 实时红框 |
| 键盘 | 列表页 `n`=新建、`/`=聚焦搜索；编辑页 `⌘S`=保存；全局 `?`=快捷键卡 |
| 反馈 | 成功 toast 短、失败 Modal 带错误码（04 表文案）；长任务=顶栏进度条 |

## 6. 组件（EP 映射 + 自研 6）

EP：ElMenu / ElTable(AD2 模板封装 LmTablePage) / ElDrawer / ElForm+校验 / ElTree(拖拽) / ElPopconfirm / ElTabs / ElDescriptions(详情 Drawer) / ElUpload / ElDatePicker / ElCascader。
**自研**：`RuleBuilder`（unlock_rule DSL 表单化，含 allOf/anyOf 嵌套一层）、`ChainEditor`（AD4 三栏联动）、`GraphEdgeCanvas`（AD5 无环校验画布）、`PathCanvas`（AD3 编排画布）、`RichEditor`（TipTap+公式）、`AuditQueue`（风险标签+三态操作）。

## 7. 响应式 / a11y / 性能

- 管理端 **≥1280 为主**（内部工具）；1024-1279 素材/属性栏可收；<1024 提示桌面使用（画布类页面硬下限 1024）；
- a11y：菜单/表格全键盘可达、表单 label 关联、错误定位滚动、色弱=图标+文字状态；
- 性能：统计图表懒加载；链编辑器/画布路由级分包；表格虚拟滚动（日志/流水 >1000 行）。

## 8. 关系与原型

- 05 §1.2 是骨架前身、§4.2 的 `UnlockRuleForm/RichEditor` 在本稿细化为 `RuleBuilder/RichEditor`；
- 10 §5.2 三工具（链编辑/路径编排/四卡审核）↔ 本稿 A12/A11/A17 一一对应；
- 原型 `docs/design/admin/index.html`：左菜单+顶栏真骨架，19 屏，🎯 三大自研工具可交互（编排器加节点/链编辑切步/画布加边成环演示）+ 列表模板与 Drawer 演示。
