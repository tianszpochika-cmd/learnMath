## 文档约定

1. **版本**：每份文档独立版本号（v主.次）；内容变更必须升版本，并在文末《变更记录》追加一行。
2. **基线**：需求文档（01）是唯一需求基线；其他文档与 01 冲突时，以 01 为准并回改。
3. **格式**：Markdown + ASCII 图；数据库以本文档为准，落地 SQL 放 `server/src/main/resources/db/`。
4. **流转**：开发机发现设计不可行时，提 issue 回改文档，不在代码中默默偏离。
