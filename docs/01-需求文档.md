## 1. 产品概述

### 1.1 产品定位

一个覆盖 **从接触数字到博士级数学** 全阶段内容的数学学习平台，**不按学段做运营分类**（规避 K12 阶段性资质），以 **知识图谱 + 难度分级 + 多学习路径** 组织内容。

核心产品主张：

> **同一个知识体系，六条不同的到达路径。** 学员可以按课程学、按图谱探索、按测评生成的计划学、按难度阶梯刷题、按专题研习、按关卡闯关——平台为不同基础、不同目标、不同学习偏好的用户提供多元选择。

### 1.2 设计原则

| 原则 | 含义 |
|------|------|
| 多元路径 | 任何知识点至少可经 2 条以上路径到达；路径之间共享进度与掌握度 |
| 掌握度为核 | 全部路径最终映射到「知识点掌握度」这一统一指标，跨路径累积 |
| 渐进解锁 | 难度阶梯、图谱前置、闯关关卡均按掌握度解锁，防止挫败 |
| AI 原生 | AI 不是附属功能，而是贯穿「测评-计划-讲解-出题-答疑」的导师角色 |
| 可降级 | 短信/微信/LLM 等第三方未配置时功能隐藏降级，核心学习闭环不依赖外部 |
| 数学特色 | LaTeX 公式、函数图像、数学输入法是一等公民 |

### 1.5 学习内核（v3.0-v3.1 · 内核一/二/三 · 决策 E1-F6）

> **产品灵魂**：让用户盯住一道题，看透「每一步为什么这样推、还能怎样推」；让每个概念回到它诞生的现实问题。数学是**可追溯的推理**与**可感知的世界**，不是符号操演。

**内核一 · 推理链解剖**（题目 = 逻辑耦合体）

| 编号 | 需求 |
|------|------|
| K-01 | 结构化解法：一题多解（解法链），每步四要素 = content + **warrant（凭什么合法，挂图谱）** + **motive（为什么想到）** + off_ramp（岔路/常见错误），步间依赖 DAG 呈现逻辑耦合 |
| K-02 | 难度新观：题目标注**耦合度**（交叉知识点数）、推理步数、是否构造 —— 难 = 耦合多 |
| K-03 | **一题五玩**：通读 / 引导预测（隐藏下一步先猜，点评"你会这么想因为…但…"，E2 可选开启+首次教学）/ 顺逆对照（综合法⇄分析法）/ 多解画廊+通法总结 / AI 苏格拉底沿链追问 |
| K-04 | **断链评价**：有客观证据或用户自报时记录解法、链版本、步骤ID、缺依据/缺动机等；AI建议待确认，证据不足显示尚未定位 → 补救直达图谱节点与动机训练；**推理能力画像**仅统计客观预测观察，自报独立展示（BR-05） |
| K-05 | **题库分层生产（E1）**：精选题人工精修 / 普通题 AI 解析转译链草稿（标"AI 整理"）/ 错题按证据定位断链，证据不足允许尚未定位 |
| K-06 | 深钻为跨路径能力：任何路径的题可进 `/deepdive`（考试辅助按 §16 BR-03 矩阵，题目深钻交卷后开放） |

**内核二 · 动机先行与现实回链**

| 编号 | 需求 |
|------|------|
| K-10 | **概念四卡**（E3 渐进补全）：起源卡（谁被什么现实问题逼出来）/ 现实原型卡（自然生活原生形态）/ 能力卡（应用地图）/ 抽象阶梯卡（现实→模型→符号逐级映射）—— 概念页**先卡后定义**；例：三角函数源于天文测角与土地测量，正弦长在波与周期现象里 |
| K-11 | **应用题 = 建模五步翻译训练**：读题标注 → 抽象设元（必答"为什么设它"）→ 列模型（逐项依据）→ 求解（复用推理链）→ **回代解释（提醒可跳过，E4，跳过留痕）**；**过程分（①-③）独立展示、不计入总分**（客观成绩仅=④客观求解判分，解答求解另行自评，P1-6 定死，⑤不计分只留痕） |
| K-12 | 双向训练：场景→编题 / 题目→还原场景；AI 点评 |
| K-13 | **现实域标签**（测量/金融/运动/自然…）聚合「从生活学数学」专题；周报推送「数学与世界」起源故事 |

**内核三 · 公式馆（v3.1 · 决策 F1-F6）**

| 编号 | 需求 |
|------|------|
| K-20 | **公式作为第三种内容实体**（与知识点、题目并列）：每条公式收录 名称+别名、LaTeX、领域分卷、难度 tier（从最简单到研究级）、**proof_status（严格证明/推导确立/经验拟合/猜想未证，F3 已证为主、未证明确标注）** |
| K-21 | 公式详情七件套：**起源**（谁/何时/被什么现实问题逼出来）、**符号表**、**推导链**（复用推理链与五玩——"凭什么成立"）、**推理范围**（成立条件+易误用边界，头部红条先于一切展示）、**应用范围**（现实域+关联题型）、**家族关系**（推广/特例/等价/逆，F4 列表+局部网图）、**变形族**（合法变形+常见错误形式） |
| K-22 | **全站公式可点（F1）**：题面/课时/深钻依据中的公式点击滑出公式卡（式子+条件红条+摘要），未收录灰态不报错；独立顶级入口 `/formulas` |
| K-23 | 三大联动：题面公式点击 ｜ 深钻依据→公式直连 ｜ 图谱节点↔公式双向挂接 |
| K-24 | **公式小练三型（F5）**：条件判断（何时不能用）/ 变形识别（合法 vs 致命错误）/ 应用匹配（现实问题选公式）—— 标准作答回 L3，进错题本与断链（错条件→缺依据） |
| K-25 | 生产（F2）：AI 批量起草 + 推导走链转译 + 人工审核分层（curated/ai_draft）；alias 治理与覆盖率看板 |

**AI 四新职责（02 §5.8 扩展）**：链转译器（管理端批量）、动机卡生成、苏格拉底讲解（**E5 默认，双模式可切**）、翻译教练。全部沿用开关/限流/3100 降级。

全量设计（对象模型、交互规格、生产流程、管理端工具、度量）→ **《10-学习引擎设计》**。

## 3. 内容体系（全端共享的地基）

### 3.1 知识图谱（升级为 DAG）

| 编号 | 功能 | 说明 |
|------|------|------|
| C-01 | 知识点树 | 任意层级树：数→算术→分数→异分母加减；不设学段边界 |
| C-02 | **前置依赖边** | 树之上叠加有向边（A 是 B 的前置），构成 **DAG**；校验无环；支撑图谱探索、自适应路径、阶梯解锁 |
| C-03 | 难度分级 | 知识点/题目均标 L1 入门 ~ L5 竞赛/研究级，可扩展 |
| C-04 | 掌握度模型 | 每用户×每知识点的掌握度 0-100：由作答正确率、近期衰减、难度加权计算；**跨路径累积共享** |
| C-05 | 标签体系 | 除图谱外的横向标签（考点、方法、思想如"数形结合"），多对多 |
| C-06 | 课程体系 | 课程→章节（树）→课时（图文 Markdown / 视频外链 / 公式富文本）；课时挂知识点；**视频一期仅外链不存储、运营自检有效性（失效展示反馈入口），上传/转码/CDN 列二期**；**试看标记 `lesson.is_preview`**（游客可见性见 §2） |
| C-07 | 题库 | 单选/多选/判断/填空/解答题；题干富文本+LaTeX+图片、选项、答案、解析、难度、知识点标签、来源 |
| C-08 | 试卷/练习组 | 手动组卷 + 按知识点/难度/题型规则抽题；支持限定"路径用卷" |
| C-09 | 批量导入 | 知识点树/题目/课程支持 CSV/Excel 结构化批量导入 |

### 3.2 数学特色交互（一等公民）

| 编号 | 功能 | 说明 |
|------|------|------|
| M-01 | LaTeX 渲染 | 全端 KaTeX：题干、解析、笔记、AI 输出中的公式统一渲染 |
| M-02 | 函数图像画板 | 输入表达式即时绘图（二维坐标系、缩放、多函数叠加）；嵌入课时内容与题目 |
| M-03 | 数学输入辅助 | 移动端公式输入工具条（分数、根号、上下标、希腊字母）；填空题支持表达式归一化判分 |
| M-04 | 图形题支持 | 题干内嵌几何图形/示意图（图片或 SVG）；动态几何画板**二期预留** |

## 4. 六大学习路径（核心差异化）

> 路径统一抽象：`learning_path` → `path_node`（节点类型可为 课时/练习组/试卷/测评/AI任务/专题/关卡）→ `user_path_progress`。六条路径共享掌握度、积分与统计。

### P1 系统课程路径（线性循序渐进）

| 编号 | 需求 |
|------|------|
| P1-1 | 课程 → 章节 → 课时线性学习，顺序解锁（可配置自由跳转） |
| P1-2 | 课时完成条件：阅读确认 + 随堂客观题全部提交且正确率≥80%；默认 practice_required，纯阅读课需显式 read_only；完成与掌握度分开（BR-02） |
| P1-3 | 学到位置记忆、断点续学、课程进度环 |
| P1-4 | 每课时配套「随堂练」，学完即测 |

### P2 知识图谱路径（自由探索）

| 编号 | 需求 |
|------|------|
| P2-1 | **图谱可视化**：DAG 力导向/分层图，节点着色表示掌握度（灰未学/绿掌握/黄薄弱/红未过前置） |
| P2-2 | 点击节点 → 知识点详情：定义、关联课时、关联题目、掌握度、前置/后继 |
| P2-3 | 前置未达标时可"越级预览"但练习需解锁（配置项） |
| P2-4 | 图谱按子树折叠（聚焦局部领域，如"线性代数"），支持搜索定位节点 |

### P3 自适应路径（AI 个性化计划）

| 编号 | 需求 |
|------|------|
| P3-1 | **入学水平测评**：分档测评卷（每大类 10-20 题，自适应：上一档正确率决定升/降档），输出能力画像与定级（L1-L5） |
| P3-2 | 测评报告：分类目正确率、优势/薄弱图谱子域、推荐起点 |
| P3-3 | **个性化学习计划**：测评结果 → 生成周计划（每日任务：课时 X + 练习 Y 分钟）；LLM 未配置时用规则引擎生成 |
| P3-4 | 计划可手动调整（增删改任务、改每日时长目标），日历视图展示 |
| P3-5 | **动态建议**：时间不足建议减量/改期；有效客观证据不足达标才建议复测/补先修；用户确认应用、可撤销，手动计划优先（BR-10） |
| P3-6 | 计划执行追踪：完成率、拖延提醒（进入通知体系） |

### P4 阶梯刷题路径（难度晋级）

| 编号 | 需求 |
|------|------|
| P4-1 | 「知识点 × 难度」矩阵形成阶梯：某知识点 L(n) 最近至多20条有效客观证据正确率≥80%且≥10题 → 解锁晋级战；晋级战客观成绩≥80%才解锁 L(n+1)（BR-01） |
| P4-2 | **每日一练**：按艾宾浩斯间隔重复，从错题与薄弱点抽题（5-10 题/日） |

## 11. 接口约定（概要）

- RESTful JSON；`/api/app/v1/**`（学员）、`/api/admin/v1/**`（管理）。
- 统一响应：`{ code: 0, message: "ok", data }`；错误码分段：1xxx 参数、2xxx 认证、3xxx 业务（**3100 = AI 未启用**、3200 = 第三方未配置）、5xxx 系统。
- 认证：`Authorization: Bearer <JWT>`，管理端独立签名域。
- 分页 `?page&size` 返回 `total`；SSE 用于 AI 流式输出。
- 详细清单在《接口设计文档》展开（下一阶段）。

## 14. 验收要点（一期）

1. `docker compose up` 四端可访问；各 `pnpm dev` 与两个 `mvn` API 本地可启动。
2. 管理端全链路：知识点树 → 图谱边（无环校验）→ 课程 → 题库 → 组卷 → **路径编排（六条均可配置）** → 社区审核 → 数据报表。
3. 学员全链路：注册登录 → **入学测评定级** → 获得学习计划 → 任选路径学习 → 做题判分 → 错题进本 → 掌握度更新 → 打卡积分段位 → 周报生成 → 社区提问获答。
4. 图谱页节点按掌握度着色正确；阶梯路径 80% 规则解锁生效；闯关星数与段位结算正确。
5. AI 配 Key 后对话/出题/讲解/计划可用且用量统计正确；未配 Key 全部入口隐藏、错误码 3100。
6. 官网 SSR 内容非空可抓取；uniapp 编译 H5 与微信小程序通过基础校验。
7. **学习内核**：深钻页五玩可用（链渲染/预测点评/顺逆对照/多解切换/苏格拉底对话）；概念页四卡先行于定义；应用题五步可走通（回代可跳但留痕）；错题断链定位+补救直达生效；推理能力画像出图。
8. **公式馆**：`/formulas` 可浏览搜索；题面公式可点开卡（含未收录灰态）；详情七件套齐全（条件红条头部展示、推导链五玩、关系局部网图、proof_status 角标）；小练三型可作答并进错题断链。
9. **合规**：注册未勾选协议不可提交；隐私政策/用户协议在端内与官网 `/legal` 可查且版本留痕；数据导出 7 天链接可用；注销冷静期后匿名化生效（全端下线）；内容安全 Provider 可配置切换。
10. **内容（12 号计划）**：MVC 示范域六路径可走通；产能实验数据回填；上线集达成 01 §13 口径。

## 16. 本轮业务规则决策（2026-09-22 · R01–R10 修复）

本节为本轮用户授权修订的需求基线。详细算法、状态和样例见 [20-学习业务规则与验收矩阵](./20-学习业务规则与验收矩阵.md)，下游文档必须同步，不能由原型自行改变。

| 规则 | 已确定需求 |
|---|---|
| BR-01 | correct_i=0/1，先乘100换算后难度加权和衰减；仅有效客观证据，至少5条才可 mastery 解锁；第15天起读写和任务统一衰减；已得解锁不撤销；阶梯达标后还须晋级战通过 |
| BR-02 | 默认 practice_required：阅读确认+随堂客观题全答且≥80%；纯阅读显式 read_only；课时完成首次奖励，阅读/达标/掌握度分别展示 |
| BR-03 | 学习/限辅助/公式参考/开卷四种辅助策略；测评、晋级战、Boss、挑战仅已审核客观题；题目解析交卷后开放；全局与题面入口、直接接口同规则 |
| BR-04 | 解答题 pending_self_assess 可退出续评，支持不会/半会/会/暂不评价；客观分与自评独立；纯解答卷无客观分；改评不重发奖励 |
| BR-05 | 断链分尚未定位/AI建议/客观观察/用户自报，保存解法+链版本+步骤稳定ID与证据快照；AI建议不进入客观推理画像；无AI可正常纠错 |
| BR-06 | 工作稿状态与完整度分开，学员/官网只读已审核发布快照；部分发布可待补全，绝不暴露待审正文；AI整理标签不替代审核 |
| BR-07 | 开始时冻结题面、答案、规则、资源与辅助策略；服务端草稿与截止时间权威；到期幂等结算；本地未同步草稿不保证跨设备恢复；历史报告不随改题改变 |
| BR-08 | 四卡固定为起源/现实原型/能力地图/抽象阶梯；公式七件套全端可达，官网可摘要；不同内容主体使用带类型深钻路由 |
| BR-09 | 来源from与目标intent分开；登录、注册、测评跳过/完成后恢复目标和可恢复试做输入；目标失效明确提示，不静默回首页 |
| BR-10 | absent/skipped/rescheduled 与学习失败分开；系统只生成带原因和版本的建议；确认应用、冲突提示、可撤销；不静默改计划或能力 |
| BR-11 | 总内容量之外必须有节点×难度×题型覆盖表，缺题显示内容筹备；有效阶梯、晋级卷与小练供给有发布门禁 |

一期验收增补：07 的 D01–D12 全部执行；文档修订、原型交互通过和真实业务验收分别记录。规则生效顺序：本节需求→20详细规格→03/04数据接口→05/09/各端UI→07用例。
