| # | 决策 | 结论 |

## 1. 定位与分工（与 15 的边界）

> Web 学习端 = **深度学习场**：大画布、双栏对照、全量信息密度。
> 移动端 = 高频短时场（15 §1）：通勤刷题、打卡、碎片复习。
> 同一功能（01 全集）两形态：**规则同源，画布不同**——链/图谱/多解在桌面用"并排画布"，在移动用"折叠/列表"。

| 场景 | Web 大屏 | 移动（15） |
|------|---------|-----------|
| 深钻顺逆 | 双画布并排 | 上下折叠 |
| 图谱 | 全屏 DAG | 列表+缩略 |
| 答题卡 | 右侧常驻面板 | 底部抽屉 |
| AI | 右侧滑出 40% | 半屏/全屏 |
| 数学输入 | 键盘为主 + 工具条辅助 | 工具条常驻 |

## 5. 交互规范（Web 专属）

| 场景 | 规格 |
|------|------|
| 快捷键 | `Enter` 提交本题/下一步 ｜ `←/→` 切题 ｜ `1-4` 选项 ｜ `F` 标记 ｜ `Esc` 关抽屉/搜索 ｜ `⌘/Ctrl+K` 搜索 ｜ **作答页生效，输入框内不劫持** |
| 判分反馈 | 练习态题下方展开解析（不弹层防打断）；✅/❌ 边框+图标+**桌面无振动**用微动效（scale pop） |
| 答题卡 | 桌面常驻右栏（WD4）；点击平滑滚动到题；交卷确认列未答数 |
| 深钻联动 | 选步卡→右栏三层同步；预取邻步内容（hover 150ms）；预测态右栏变点评区 |
| 图谱 | 滚轮缩放、框选子树、节点拖拽微调（仅视图）；搜索定位=镜头飞入+高亮脉冲 |
| 作答保护 | 草稿 localStorage 每题即存 + beforeunload 守护；倒计时 5/1 分钟提醒；0 自动交 |
| AI 面板 | WD6：气泡→右滑 40%；SSE 流式+公式节流；深钻内唤起带 `stepSeq` 上下文；3100配置关闭=入口不渲染；3006=当前辅助不允许，提示回作答 |
| 三态 | Empty/Skeleton（作答禁骨架）/Error+重试；离线横幅 |
| 入场 | fade-up 400ms stagger 60ms；reduced-motion 全降级 |

## 7. 响应式 / a11y / 性能

| 断点 | 行为 |
|------|------|
| ≥1280 | 双栏全量（深钻 8+4、作答 7+3） |
| 1024-1279 | 图谱/深钻全宽；作答右栏 280px |
| 768-1023 | **平板**：作答右栏→抽屉；深钻右栏→底部三段折叠；图谱保留 |
| <768 | 提示"下载移动版/H5"（跳转 15 形态）；紧急降级=按 1024 规则单列 |

a11y：快捷键可 `?` 查看且可关；图表 aria 摘要；对比度 AA；焦点可见；颜色+图标双编码。
性能：图谱 large 模式+子树懒加载（2000 节点）；KaTeX 按需；深钻/图谱路由级分包；ECharts 异步引入。

## 8. 关系与原型

- **05** = IA/路由/通用组件权威；**本稿 = Web 页面形态与线框权威**；**14/15 = 官网/移动权威**——三者共享 05 §5 tokens，边界见 14 §11、15 §9；
- 09 各链在 Web 的形态按本稿（如 I8 深钻=W05、I4 测评=W11）；
- 原型 `docs/design/web/index.html`：左屏目录（18 屏）+ 桌面窗口框（1280×800 视口），🎯 核心链可点：登录→首页→课时→作答(右栏答题卡+判分)→报告→错题断链→**深钻五玩双栏**→**图谱画布**→AI 侧滑→公式→我的注销。

## 10. 本轮Web状态补充（20 BR-01–BR-10）

W04区分阅读确认与课时完成，默认练习达标才推进；W08显示开考辅助规则、草稿同步与冲突、服务器时限；W09加入自评区（待评数、参考解析、四选、退出续评/改评），纯解答无客观成绩。
