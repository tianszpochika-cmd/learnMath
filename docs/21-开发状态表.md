## 0. 执行原则（本机专属约束）

1. **只写代码 + 纯逻辑测试**：允许的验证 = 编译（`mvn compile` / `vue-tsc` 级）与**纯 JVM 单测**（domain 纯逻辑、无 Spring 上下文、无 DB/Redis/端口）；**禁止** `spring-boot:run`、`docker compose up`、起 Vite dev、连库执行。
2. **JAVA_HOME 只在命令进程内传**（`$env:JAVA_HOME='…\jdk-25'` 一次性），不持久修改本机环境。
3. **状态语义**：⬜ 未开始 → 🔵 开发中 → **✅ 开发完成**（代码+纯逻辑测试绿+提交）→ 🟪 待修复（留给后续本地测试/修复阶段）。
4. **"✅ 开发完成"的判定**：① 代码落库并 commit ② 关联单测（或结构校验脚本）通过 ③ 与 19/20 的 BR 规则冲突为 0 ④ 本表更新。**✅ ≠ 业务验收通过**（运行时验收归 D01-D12，测试阶段执行）。
5. 依据 18 §7：DR-01–DR-10 的实现项并入对应模块 DoD；`check-design-contracts.mjs` 只作设计文本校验。
