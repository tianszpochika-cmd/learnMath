## 1. 通用约定

| 项 | 约定 |
|----|------|
| 协议 | HTTPS（生产）/ HTTP（本地）；JSON，UTF-8 |
| 学员域 | `learn-app-api`，前缀 `/api/app/v1`，默认端口 8080 |
| 管理域 | `learn-admin-api`，前缀 `/api/admin/v1`，默认端口 8081 |
| 认证 | `Authorization: Bearer <accessToken>`；未标注「公开」的接口必带 |
| 响应 | `{ "code": 0, "message": "ok", "data": ... }`；HTTP 状态码恒 200（网关/5xx 除外），业务态看 `code` |
| 分页 | 入参 `?page=1&size=20`（size≤100）；出参 `data: { items, total, page, size }` |
| 时间 | 入出参 ISO-8601 字符串 `2026-09-28T10:00:00`；日期 `yyyy-MM-dd` |
| 幂等 | 提交类（attempt 交卷、打卡）以状态机/UNIQUE 约束幂等，重复提交返回原结果 |
| 追踪 | 响应头 `X-Request-Id`；管理端写操作自动入审计（03 T46） |
| SSE | 仅 AI 流式，见 §6 |

### 请求/响应示例

```jsonc
// POST /api/app/v1/auth/login  Body
{ "account": "13800000000", "password": "***", "scene": "web" }
// 响应
{ "code": 0, "message": "ok",
  "data": { "accessToken": "eyJ...", "refreshToken": "eyJ...",
            "user": { "id": 1, "nickname": "同学A", "avatar": "", "points": 120, "rankTier": 2 } } }

// 错误
{ "code": 2001, "message": "账号或密码错误", "data": null }
```

## 2. 认证与令牌

| 项 | 学员域 | 管理域 |
|----|--------|--------|
| Header | `Authorization: Bearer <access>` | 同左（独立密钥签发，互不可用） |
| Access TTL | 2 小时 | 2 小时 |
| Refresh | `POST .../auth/refresh {refreshToken}` → 轮换 | 同左（TTL 8h） |
| 401 语义 | 2001 未登录 / 2003 过期（引导刷新）/ 2004 越权 | 同左 + 登录锁定 2005 |

## 3. 错误码总表

| 段 | 含义 | 示例 |
|----|------|------|
| 0 | 成功 | — |
| 1xxx | 参数 | 1001 参数校验失败；1002 验证码错误/过期；1004 请求过于频繁 |
| 2xxx | 认证授权 | 2001 未登录；2003 Token 过期；2004 无权限；2005 账号锁定；2006 账号已存在 |
| 3xxx 30xx | 内容/学习 | 3001 课程已下架；3002 课时未解锁；3003 试卷不存在；3004 已作答不可重开 |
| 3xxx 31xx | AI | **3100 AI 未启用**；3101 AI 限流/积分不足；3102 AI 上游失败请重试 |
| 3xxx 32xx | 第三方 | **3200 该功能未配置**（短信/微信）；3201 短信发送频繁；3202 微信授权失败 |
| 3xxx 33xx | 图谱/路径 | 3310 图谱成环；3311 前置未满足不可解锁；3312 阶梯晋级条件未达 |
| 3xxx 34xx | 社区 | 3401 内容命中审核；3402 已被删除；3403 重复点赞 |
| 3xxx 35xx | 游戏化 | 3501 今日已打卡；3502 补签卡不足；3503 积分余额不足 |
| 5xxx | 系统 | 5000 内部错误；5003 触发限流；5004 服务暂不可用 |

## 6. SSE 协议（AI 流式）

```
GET/POST /api/app/v1/ai/{chat|explain}   Accept: text/event-stream
```

| event | data | 说明 |
|-------|------|------|
| `delta` | `{"text":"增量文本"}` | 流式增量（含 `$katex$` 由前端渲染） |
| `meta` | `{"conversationId":9,"tokens":0}` | 首帧：会话信息 |
| `done` | `{"usage":{"promptTokens":12,"completionTokens":34},"costMs":820}` | 结束 |
| `error` | `{"code":3100,"message":"AI 未启用"}` | 中断错误（随后连接关闭） |

前端：`fetch` + `ReadableStream` 解析（EventSource 不能带 Authorization 头，生产可用 fetch-polyfill 或短时 ticket 查询参）；断线重连 = 前端带 `conversationId` 重发，服务端按最近一轮补齐（一期简化：提示“重新提问”）。

**示例（chat）**：

```
> {"question":"为什么 0.999... = 1？","context":{"questionId":1001}}
< event:meta  data:{"conversationId":9}
< event:delta data:{"text":"这是一个经典问题，我们从极限角度看……"}
< event:done  data:{"usage":{...},"costMs":1200}
```
