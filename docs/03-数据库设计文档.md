## 1. 设计规范

| 项 | 约定 |
|----|------|
| 库 | `learnmath`，InnoDB，`utf8mb4_0900_ai_ci`，连接时区 Asia/Shanghai |
| 主键 | `id BIGINT UNSIGNED AUTO_INCREMENT`（雪花 ID 一期不用，量级不需要） |
| 公共字段 | `created_at DATETIME(3)`、`updated_at DATETIME(3) ON UPDATE`；内容类表加 `deleted TINYINT(1) DEFAULT 0`（逻辑删） |
| 枚举 | `TINYINT` + `COMMENT`（如 `status TINYINT COMMENT '1上架 2下架'`）；跨表状态语义统一 |
| 外键 | **不建物理外键**，引用完整性由应用层保证；孤儿风险靠定期巡检 SQL |
| 金额/积分 | 积分用 `INT`（非钱）；预留订单表金额用 `DECIMAL(10,2)` |
| 索引 | 每表必有 `created_at` 普查索引按需；高频查询列建复合索引（见 §5） |
| JSON 列 | `JSON` 类型用于规则/快照（rule_json、payload、rule），不作频繁条件查询 |

## 2. ER 总览（分域）

```
【内容域】                              【路径与测评域】
course 1─* chapter 1─* lesson *─* question *─* knowledge_node
                                          │            ▲
paper 1─* paper_question *─1 question     │            │ knowledge_edge(from→to 前置依赖)
                                          │            │
learning_path 1─* path_node（ref→lesson/quiz/paper/assessment/...）
                      │                    mastery(user×node 掌握度) ◄─ 事件回写
                      ▼
            user_path_progress
assessment 1─* assessment_record(user, 定级)
learning_plan 1─* plan_task          special_topic 1─* topic_node

【行为域】
user 1─* attempt 1─* attempt_answer *─1 question
user 1─* wrong_book *─1 question       user 1─* progress(lesson)
user 1─* check_in / point_transaction / user_achievement / user_daily_task
user 1─* note / favorite               stat_daily(user×date)   study_report

【社区与AI域】
post 1─* reply   report_record(举报)   notification   ai_conversation 1─* ai_message

【系统域】
user / admin_op_log / config / tag / tag_rel / achievement / daily_task
order / member（预留，一期建表不启用）
```

## 4. 核心表字段定义

> 以下省略公共字段（id/created_at/updated_at，内容类含 deleted）；类型为 MySQL 8 语法。

### T01 user

| 字段 | 类型 | 说明 |
|------|------|------|
| username | VARCHAR(32) UNIQUE | 账号（可选注册） |
| phone | VARCHAR(20) UNIQUE | 手机号 |
| email | VARCHAR(64) UNIQUE | 邮箱 |
| password | VARCHAR(100) | BCrypt，可为空（纯微信注册则随机） |
| nickname | VARCHAR(32) | 昵称 |
| avatar | VARCHAR(255) | 头像 URL |
| wechat_openid | VARCHAR(64) UNIQUE | 微信 openid（小程序/App） |
| wechat_unionid | VARCHAR(64) | 开放平台 unionid（预留多端归一） |
| register_channel | TINYINT | 1账号 2手机 3邮箱 4微信 |
| role | TINYINT | 0学员（预留扩展） |
| status | TINYINT | 1正常 2禁用 |
| points | INT | 当前积分（余额，权威为流水之和，定时对账） |
| level_no | TINYINT | 测评定级 L1-L5 缓存 |
| member_type | TINYINT | 0免费（预留 1月度 2年度） |
| member_expire_at | DATETIME | 预留 |
| last_login_at | DATETIME | |

索引：phone/email/username/wechat_openid UNIQUE；(status, created_at)

### T02 knowledge_node / T03 knowledge_edge

knowledge_node：`parent_id BIGINT 0=根`、`name VARCHAR(64)`、`description VARCHAR(500)`、`difficulty_baseline TINYINT(1-5)`、`sort INT`、`status TINYINT(1上架 2下架)`、`path_thumb VARCHAR(255)`（图谱缩略图，预留）
索引：(parent_id, sort)、name

knowledge_edge：`from_id`、`to_id`、`type TINYINT(1必须 2推荐)`；UNIQUE(from_id,to_id)；**应用层无环校验**（02 §5.1）；索引 (to_id)

### T06 course / T07 chapter / T08 lesson

course：`title VARCHAR(100)`、`cover VARCHAR(255)`、`description TEXT`、`level_base TINYINT`、`sort INT`、`status TINYINT(1上架 2下架 3草稿)`、`is_free TINYINT(1免费 2会员——预留门禁)`
chapter：`course_id`、`parent_id`（树）、`title VARCHAR(100)`、`sort INT`
lesson：`chapter_id`、`title`、`type TINYINT(1图文 2视频)`、`content MEDIUMTEXT(Markdown+LaTeX)`、`video_url VARCHAR(255)`、`duration INT秒`、`practice_json JSON`（随堂练题组引用）、`sort INT`、`status`
索引：chapter(course_id,parent_id,sort)、lesson(chapter_id,sort)

### T09 question / T10 question_knowledge

question：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | TINYINT | 1单选 2多选 3判断 4填空 5解答 |
| stem | MEDIUMTEXT | 题干（Markdown+LaTeX+图片） |
| options | JSON | 选择题选项 `[{key,text}]` |
| answer | VARCHAR(500) | 标准答案；填空多空 `||` 分隔；解答为要点 JSON |
| analysis | MEDIUMTEXT | 解析 |
| difficulty | TINYINT | 1-5 |
| source | TINYINT | 1官方 2导入 3AI生成 |
| status | TINYINT | 1可用 2停用 3待审 |
| judge_config | JSON | 归一化开关/容差（02 §5.4） |
| owner_user_id | BIGINT | source=AI 时的归属（临时题仅本人可见） |

索引：(status,difficulty)、(source,status)；正文检索用 LIKE 一期 + 可选 FULLTEXT(stem)
question_knowledge：`question_id`、`node_id`、`weight TINYINT`，UNIQUE(question_id,node_id)，索引 node_id（抽题主查询）

### T11 paper / T12 paper_question

paper：`title`、`type TINYINT(1手动 2规则)`、`rule_json JSON`（知识点/难度/数量规则）、`duration INT分钟`、`total_score INT`、`status TINYINT`、`path_ref VARCHAR(16)`（路径引用标记，可空）
paper_question：`paper_id`、`question_id`、`seq INT`、`score INT`，索引 (paper_id,seq)

### T15 learning_path / T16 path_node

learning_path：`code VARCHAR(4) UNIQUE(P1..P6)`、`name`、`type TINYINT`、`config JSON`（如 P4 阈值 0.8/minCount 10；P6 赛季开关）、`status`
path_node：`path_id`、`ref_type TINYINT(1lesson 2quiz 3paper 4assessment 5ai 6topic 7boss 8checkpoint)`、`ref_id BIGINT`、`title VARCHAR(100)`、`unlock_rule JSON`（02 §5.3 DSL）、`seq INT`、`map_x/map_y INT`（P6 关卡坐标）、`star_rule JSON`
索引 (path_id,seq)

### T17 mastery

`user_id`、`node_id`、`score DECIMAL(5,2) NULL`（0-100，无有效证据为NULL）、`last_eligible_at DATETIME(3)`、`calculated_at DATETIME(3)`、`eligible_count SMALLINT`、`model_version VARCHAR(16)`、`streak INT`、`history_json JSON`（近20条有效客观证据，含answerId/族/version/难度/正误/时间，供20 BR-01复算）
UNIQUE(user_id,node_id)；索引 (user_id,score)（雷达图批量拉取）

### T18 user_path_progress

`user_id`、`path_id`、`current_node_id`、`status TINYINT(0进行 1完成 2放弃)`、`star SMALLINT`（P6累计星）、`last_active_at`，UNIQUE(user_id,path_id)

### T19/T20 assessment & record

assessment：`name`、`rule_json JSON`（分档、升降、终止）、`dims_json JSON`（维度↔知识点映射）、`status`
assessment_record：`user_id`、`assessment_id`、`result_level TINYINT(1-5)`、`dim_score_json JSON`、`start_at`、`end_at`、`status TINYINT(1进行 2完成)`
索引 (user_id,assessment_id,created_at)

### T21/T22 learning_plan & plan_task

learning_plan：`user_id`、`title`、`source TINYINT(1规则 2AI 3手动)`、`weekly_goal_json`、`status TINYINT(1生效 2完成 3作废)`、`date_from/date_to`
plan_task：`plan_id`、`user_id`、`date`、`ref_type/lesson|quiz|paper|review`、`ref_id`、`title`、`estimate_minutes`、`status TINYINT(0待办 1完成 2跳过 3缺席 4改期)`、`sort`
索引 (user_id,date,status)

### T23 stage_rank

`user_id` UNIQUE、`rank_tiny TINYINT(1青铜..7宗师)`、`week_points INT`、`total_stars SMALLINT`、`season VARCHAR(16)`、`updated_at`

### T24/T25 challenge & record

challenge：`title`、`paper_id`、`start_at/end_at`、`reward_points`、`status`
challenge_record：`challenge_id`、`user_id`、`attempt_id`、`score`、`rank_no INT`，索引 (challenge_id,score desc)

### T26 attempt / T27 attempt_answer

attempt：`user_id`、`paper_id`、`path_node_id`（可空，来源路径）、`mode TINYINT(1练习 2试卷 3每日一练 4挑战 5随堂 6测评 7晋级战 8Boss)`、`status TINYINT(1进行 2已交判分中 3已终结 4待自评)`、`objective_possible/objective_earned DECIMAL(8,2)`（无客观题分母=0，正确率返回NULL）、`duration_second`、`started_at/submitted_at`、`report_revision INT`、`effects_pending JSON`（待补偿消费清单）
attempt_answer：`attempt_id`、`question_id`、`seq`、`user_answer VARCHAR(1000)`、`is_correct TINYINT(NULL=非客观题或尚未判分)`、`self_assess TINYINT(NULL待评 0不会 1半会 2会 3暂不评价)`、`self_assess_revision INT`、`score`、`duration_second`、`error_tag TINYINT(1粗心 2不会 3遗忘)`、`judge_detail JSON`
索引：attempt(user_id,created_at)、(paper_id)；attempt_answer UNIQUE(attempt_id,seq)

### T28 wrong_book

`user_id`、`question_id`、`wrong_count INT`、`mastered TINYINT`、`error_tag TINYINT`、`last_wrong_at`、`next_due_date`（SRS）、`redo_count`
UNIQUE(user_id,question_id)；索引 (user_id,mastered,next_due_date)

### T29 progress（课时）

`user_id`、`lesson_id`、`status TINYINT(0未学 1进行 2完成)`、`duration_second INT`、`last_position INT`（视频断点）、`completed_at`，UNIQUE(user_id,lesson_id)

### T30/T31 check_in & point_transaction

check_in：`user_id`、`date DATE`、`streak INT`（当日快照）、`make_up TINYINT(补签)`，UNIQUE(user_id,date)
point_transaction：`user_id`、`delta INT`（正负）、`type TINYINT(1做题 2打卡 3任务 4挑战 5社区 6消耗 7管理员调整)`、`biz_type VARCHAR(32)`、`biz_id BIGINT`、`balance_after INT`、`remark VARCHAR(100)`
索引 (user_id,created_at)；**UNIQUE(user_id,biz_type,biz_id,type)** 防重复记账

### T32/T33 achievement & user_achievement

achievement：`code VARCHAR(32) UNIQUE`、`name`、`icon`、`rule_json JSON`（如 `{"event":"PaperPassed","times":1,"scoreGte":100}`）、`points`、`sort`
user_earned：`user_id`、`achievement_id`、`unlocked_at`，UNIQUE(user_id,achievement_id)

### T34/T35 daily_task & user_daily_task

daily_task：`code`、`name`、`rule_json`（事件+阈值）、`points`、`status`
user_daily_task：`user_id`、`date`、`task_id`、`progress INT`、`done TINYINT`，UNIQUE(user_id,date,task_id)

### T36/T37 note & favorite

note：`user_id`、`ref_type TINYINT(1课时 2题目 3知识点 4帖子)`、`ref_id`、`title`、`content MEDIUMTEXT`、`anchor VARCHAR(100)`（锚点描述）
favorite：`user_id`、`ref_type/ref_id`、`folder VARCHAR(32)`（分组名，默认"默认收藏"），UNIQUE(user_id,ref_type,ref_id)

### T38/T39 stat_daily & study_report

stat_daily：`user_id`、`date`、`study_second INT`、`question_count INT`、`correct_rate DECIMAL(5,2)`、`check_in TINYINT`、`path_nodes_done INT`，UNIQUE(user_id,date)
study_report：`user_id`、`period_type TINYINT(1周 2月)`、`period_key VARCHAR(10)`（如 2026-W37）、`data_json JSON`（指标快照）、`ai_comment TEXT`（可空）、`created_at`，UNIQUE(user_id,period_type,period_key)

### T40/T41/T42 post & reply & report_record

post：`user_id`、`title VARCHAR(100)`、`content MEDIUMTEXT`、`ref_type TINYINT(0无关联 1题目 2知识点 3课时 4专题)`、`ref_id`、`status TINYINT(1待审 2通过 3删除 4驳回)`、`top TINYINT`、`essence TINYINT`、`view_count`、`like_count`、`reply_count`、`last_reply_at`
reply：`post_id`、`user_id`、`parent_id`（楼中楼，一期两层）、`content MEDIUMTEXT`、`accepted TINYINT`（采纳）、`status`、`like_count`
report_record：`target_type TINYINT(1帖 2回复)`、`target_id`、`reporter_id`、`reason VARCHAR(200)`、`status TINYINT(1待处理 2成立 3不成立)`、`handle_result VARCHAR(200)`、`handler_id`
索引：post(status,last_reply_at desc)、(ref_type,ref_id)；reply(post_id,created_at)

### T43 notification

`user_id`、`type TINYINT(1系统 2学习 3社区 4审核)`、`title`、`content VARCHAR(500)`、`link VARCHAR(255)`、`read TINYINT`，索引 (user_id,read,created_at desc)

### T44/T45 ai_conversation & ai_message

ai_conversation：`user_id`、`feature TINYINT(1答疑 2讲解 3出题 4计划 5诊断)`、`ref_type/ref_id`（关联题/知识点）、`title`、`status`
ai_message：`conversation_id`、`role TINYINT(1用户 2AI)`、`content MEDIUMTEXT`、`tokens INT`、`cost_ms INT`
索引 (user_id,created_at)；管理端用量：ai_message 按日聚合视图

### T46/T47 admin_op_log & config

admin_op_log：`admin_id`、`action VARCHAR(64)`、`target_type VARCHAR(32)`、`target_id`、`detail JSON`、`ip VARCHAR(45)`，索引 (created_at desc)
config：`cfg_key VARCHAR(64) UNIQUE`、`cfg_value TEXT`、`description`、`group_name VARCHAR(32)`（ai/sms/wechat/exam/gamification）

### T48/T49 order & member（预留）

order：`user_id`、`sku_type TINYINT`、`amount DECIMAL(10,2)`、`pay_channel TINYINT`、`status TINYINT`、`trade_no`
member：`user_id`、`type`、`start_at`、`end_at`、`order_id` —— 一期仅建表 + 注释“未启用”。

## 5. 关键查询与索引对照

| 高频查询 | 索引 |
|---------|------|
| 抽题：知识点×难度×可用 | question_knowledge(node_id) + question(status,difficulty) |
| 我的错题（分类/到期） | wrong_book(user_id,mastered,next_due_date) |
| 雷达图批量掌握度 | mastery(user_id,score) |
| 排行榜 | Redis zset 为准，DB 仅 stat_daily 兜底 |
| 首页动态/社区列表 | post(status,last_reply_at desc) |
| 路径节点求值 | path_node(path_id,seq) + mastery 缓存 |
| 图谱边查询 | knowledge_edge(from_id)/(to_id) |
