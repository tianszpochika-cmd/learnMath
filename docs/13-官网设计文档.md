## 1. 定位与设计原则（v2.0 增补）

> 官网 = **产品灵魂的第一眼 + 搜索流量的着陆场 + 免费内容的学习前厅**。
> 学员端的三内核资产（四卡、公式、题库）在官网以**公开只读**形态二次绽放——一次生产，三处收益（学员端 / 官网 SEO / 周报推送）。

| 原则 | 落地 |
|------|------|
| 内容引擎公开化（F-1） | 词条=四卡、公式页=七件套公开子集、每日一题=题库、年表=起源素材 —— 全部复用 12 号流水线 |
| 每页双职责 | 每个页面同时有 CTA 与语义化正文（转化+检索） |
| 数字真实 | 背书取 12 号上线集口径，不虚报 |
| 可降级 | AI 宣传只展示形态，不依赖运行时 LLM |
| 渐进门槛 | **公开内容不设登录墙（V5）**；注册引导靠上下文 CTA |

## 3. 站点结构（v2.0 终表 · 六大区）

```
① 首页 /                          （12 模块，见 §4.1）
② 产品区（19 页型）
   /features                      功能枢纽（8 锚点导航）
   /features/:slug ×8             功能详情模板：deepdive/graph/formula/ai/wrongbook/community/gamification/assessment
   /paths · /paths/:slug ×6       六路径总览 + 详情（course/graph/plan/ladder/special/challenge）
   /pricing                       价格页：当前全部免费声明 + 会员能力预览（预留态）
   /changelog                     产品更新日志（article type=动态 复用）
   /roadmap                       公开路线图（阶段卡片 + 反馈入口）
③ 学习资源区 = SEO 引擎（9 页型 · 数百动态页）
   /glossary · /glossary/:slug    数学词条百科（概念四卡公开版；100+ 词条）
   /formulas · /formulas/:slug    公式公开预览（头部+条件红条+推导摘要；600+ 页）
   /daily                         每日一题（V5 完全公开：题+解析+链摘要+倒计时）
   /timeline                      数学年表（横向可拖拽时间线，节点→词条）
   /tools                         工具页：函数图像画板 + 公式速查表
   /blog · /blog/cat/:cat · /blog/tags/:tag · /blog/:slug   分类/标签/详情
   /search                        全站搜索结果（词条/公式/文章/路径分栏）
④ 信任区（7+ 页）
   /cases · /cases/:slug          学习案例（article type=案例）
   /manifesto                     产品宣言（三内核理念长文）
   /help · /help/:slug            帮助中心（article type=帮助 + category）
   /faq                           FAQ 聚合（FAQPage JSON-LD）
   /media                         媒体素材包（logo/截图/介绍文打包）
   /status                        服务状态页（API/站点/小程序三行灯 + 历史）
⑤ 转化区（5 页）
   /download                      下载中心（H5/三码/App）
   /events · /events/:slug        活动/挑战赛公开页（报名→注册）
   /community-preview             社区精选预览（热门问答引流登录）
   /contact                       联系我们（表单→邮件）
⑥ 合规与骨架
   /legal/:type                   隐私政策/用户协议（article type=legal）
   404 / 500                      品牌化错误页（搜索框回首页）
   robots.txt · sitemap.xml · /rss · /sitemap_index   自动化
```

**页型统计**：静态页型 **40+**；动态页 = 词条 100+ × 公式 600+ × 文章/案例/帮助/年表按内容滚动 → **数百上千真实页面**。
**内容源映射**：词条↔`knowledge_node+narrative`、公式↔`formula`、每日题↔`daily_question`、年表/案例/帮助/日志/活动↔`article(type 5/6/7/8…)`、状态↔`/stats/public`+健康检查。

### 4.2 路径页模板（×6，v1 不变）

Hero 带（分类色）→ §1 为什么（drop-cap 叙事）→ §2 适合谁/不适合 → §3 三步 → §4 真实界面 → §5 FAQ → §6 CTA 带（from 归因）→ §7 相关文章。

### 4.3 功能枢纽与详情页

- `/features`：8 锚点分区（每区=演示图+3-5 行语义正文+CTA），页尾 [全部功能] 进详情；
- `/features/:slug` **统一模板**：H1+演示视频位 → 痛点叙事 → 三步"怎么用" → **真实场景案例**（链接 cases）→ 边界说明（做什么/不做什么，建立信任）→ FAQ×3 → CTA（from=features/{slug}）。8 篇 slug：`deepdive / graph / formula / ai / wrongbook / community / gamification / assessment`。

| 页型 | 模块流（自上而下） |

## 7. 获客与探索链（09 联动）

- **L0 官网获客链**（v1 保留）：着陆→灵魂模块→双 CTA→注册/下载（from 归因）；
- **L13 资源探索链** 🆕（进 09）：`搜索/分享 → 词条/公式/每日题（公开深读）→ 接龙/相关继续浏览 → 学习语境 CTA → 注册（from=glossary|formula|daily）→ 汇入 L1`；异常：无登录墙（V5）、空态推荐、埋点=词条深度>2 视为高意向。

## 9. 技术与工程（04/08 联动）

- Nuxt 3.21 SSR + Node 20.19.5（S1 基线）；ISR 同 v1；
