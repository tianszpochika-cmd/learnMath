## 3. 状态管理（Pinia）

| Store | 职责 | 持久化 |
|-------|------|--------|
| useAuthStore | token/refresh、用户身份、登录渠道 | localStorage（access 内存 + refresh 持久） |
| useUserStore | profile、未读数、段位积分 | — |
| useAttemptStore | **当前作答会话**：题目列表、已答、计时、草稿 | sessionStorage（防刷新丢卷） |
| usePathStore | 六路径进度、当前路径节点解锁态 | — |
| usePlanStore | 今日任务、日历数据 | — |
| useMasteryStore | 图谱子图与掌握度（按子树缓存） | — |
| useNotificationStore | 未读、列表 | — |
| useAppStore | 全局配置（/ai/status 等开关）、主题 | localStorage |

原则：服务端数据不建全局缓存（各页面自取），仅上述跨页状态入库；mutation 走 api-client 统一回刷。

## 4. 组件规范

### 4.1 目录与命名

```
src/
├─ components/
│  ├─ base/            # 通用：LmButton、LmEmpty、LmPagination、LmUpload…
│  ├─ learn/           # 学习域：QuestionCard、AnswerSheet、OptionGroup、
│  │                   #   FillBlankInput、ScoreRing、MasteryRadar、HeatmapCalendar
│  ├─ graph/           # GraphView(ECharts graph)、NodeDetailPanel
│  ├─ markdown/        # MarkdownKaTeX（渲染器，四端复用逻辑→packages/shared）
│  └─ ai/              # AiChatPanel（SSE 客户端）、AiExplainDrawer
├─ views/              # 路由页（PascalCase 目录）
├─ composables/        # useSse、useCountdown、usePagination…
├─ stores/  router/  api/
```

- 组件 PascalCase；单文件组件名 = 文件名；emit 事件 `onXxx` 前缀取消（用 `update:xxx` v-model 风格）。
- **四端复用**：纯逻辑（判分展示辅助、SSE 解析、Markdown+KaTeX 渲染管线、时间/积分格式化）放 `packages/shared`；请求放 `packages/api-client`（平台注入 baseUrl/tokenProvider，见 §6）。

### 4.2 核心复用组件规格

| 组件 | 关键点 |
|------|--------|
| MarkdownKaTeX | markdown-it + KaTeX，白名单 sanitize，图片懒加载；题干/解析/AI 输出统一入口 |
| QuestionCard | 按 type 渲染选项组/填空/解答；作答态/判分态/解析态三态 props |
| AnswerSheet | 答题卡导航：未答高亮、标记题、倒计时（0 按钮式，移动端底部抽屉） |
| GraphView | ECharts `graph` 布局：force→层级可切；节点色 = 掌握度四档（灰/红/黄/绿）；点击开 NodeDetailPanel；>500 节点启用 `large` + 折叠子树 |
| MasteryRadar / TrendChart / Heatmap | ECharts 封装，统一 `lm` 主题（§5） |
| AiChatPanel | fetch-SSE 解析（04 §6），`$katex$` 增量渲染节流 50ms；错误码 3100 显示“未启用”态 |
| RichEditor（admin） | TipTap（LaTeX 插件、图片上传、公式面板），导出 Markdown 存 content |
| TreeDnd（admin） | 章节/知识点树：拖拽排序+移动（调 /move 接口） |
| UnlockRuleForm（admin） | DSL 表单化：类型下拉 → 参数字段（mastery/ladder/stars/paper_pass/组合） |

## 5. 视觉与主题

| 项 | 决定 |
|----|------|
| 设计语言 | 清晰、专注、数理感：大量留白 + 网格辅助线元素（首页/图谱页） |
| 主色 | `--lm-primary: #2F6BFF`（理性蓝）；辅 `--lm-accent: #FFB020`（积分/成就金） |
| 语义色 | 正确 `#22C55E` / 错误 `#EF4444` / 薄弱 `#F59E0B` / 未学 `#9CA3AF`（与图谱四档一致） |
| 模式 | CSS 变量驱动，一期仅亮色，**预留暗色**（`prefers-color-scheme` 全变量已抽离） |
| 字体 | 正文系统栈；公式 KaTeX 默认；标题数字可用 `font-variant-numeric: tabular-nums` |
| 图表 | ECharts theme `lm`：主色系列、圆角、无边框网格 |
| 响应式 | web 断点 1280/1600；uniapp rpx（750 基准），点击热区 ≥88rpx |

管理端：Element Plus 默认主题 + 主色覆盖（`--el-color-primary: #2F6BFF`），密度 compact。

## 6. api-client 设计（packages/api-client）

```ts
// 平台无关请求核：web/admin 注入 axios；uniapp 注入 uni.request
createApi<T>({ baseUrl, getToken, onRefresh })
// 模块化导出（04 接口逐一对应）
api.auth.login(...)   api.path.paths()   api.community.posts(...)  adminApi.questions.list(...)
```

- 统一拦截：附 token、401→refresh 重试一次（单飞行队列）、错误码→i18n 文案/全局 toast（3100/3200 静默降级不上抛）。
- 类型：M1 由 OpenAPI 生成（04 §7）或手写与 DTO 同名接口；`shared` 提供枚举/常量（QuestionType、PathCode、ErrorCode）。
- SSE 不走 axios：`packages/shared/src/sse.ts`（fetch stream 解析器，四端复用）。

## 7. 性能与体验指标（对齐 01 §9）

| 指标 | 目标 | 手段 |
|------|------|------|
| 首屏 LCP | <2s | 路由分包、首页聚合接口、图片 CDN/懒加载、`manualChunks` 拆 echarts/katex |
| 图谱渲染 | 2000 节点流畅 | large 模式、子树按需拉取、canvas 渲染 |
| 作答页 | 零丢答 | sessionStorage 草稿 + beforeunload 守护 + 心跳上报 |
| SSE | 首字 <800ms | 上游流式 + 前端 50ms 节流渲染 |
| 移动端 H5 | 首屏 <2.5s | 分包、tab 懒加载、关 echarts 换轻量图表（小程序 canvas 2d） |

## 8. 无障碍与国际化预留

- 语义化标签、焦点可见、图表提供文字摘要（`aria-label`）；颜色不作为唯一语义（配图标/文字）。
- 文案全量常量化（`shared/locales/zh-CN.ts`），组件不写死中文 → 二期 i18n 只接翻译。
