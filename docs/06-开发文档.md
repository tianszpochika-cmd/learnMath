## 1. 双机协作模式（本项目特有）

| 机器 | 角色 | 职责 |
|------|------|------|
| **文档机**（本机，低配） | 需求/设计 | 编写与维护 docs/01-08、评审变更、git 提交推送 |
| **开发机**（大内存） | 编码/构建/运行 | `git pull` 后脚手架、编码、测试、本地联调、部署演练 |

**流转规则**：
1. 一切设计决策先落文档（升版本+变更记录）→ 提交 → 开发机 pull 后实施；
2. 开发中发现设计不可行：**不静默偏离**，开 issue 回改文档再改码；
3. 分支：文档与代码同仓库同分支策略（§6），文档变更走 `docs/xxx` 分支或直接 develop。
4. 大文件/产物不进 git（.gitignore 已含 node_modules/target/dist）。

### ⚠️ 与 cloudstudy 同机共存注意事项（若开发机也跑 cloudstudy）

| 项 | 处理 |

## 5. 本地开发流程

```powershell
# 0) 一次性
git clone <repo> && cd learnMath
nvm use 24.21.0
setx JAVA_HOME "C:\Program Files\Java\jdk-25"    # 或本终端 $env:JAVA_HOME=...
pnpm install

# 1) 基础设施
docker compose up -d          # MySQL 13307 + Redis 16380
# 执行迁移：按序运行 db/migration/V*.sql（或 Flyway，见 §9）

# 2) 后端（两个终端）
cd server
mvn spring-boot:run -pl learn-app-api      # :8080
mvn spring-boot:run -pl learn-admin-api    # :8081

# 3) 前端（按需，各终端）
pnpm dev:web        # :28180
pnpm dev:admin      # :28181
pnpm dev:official   # :28182
pnpm dev:uniapp:h5  # :28183
```

启动顺序：infra → api → 前端；健康检查 `GET :8080/actuator/health`（M1 引入 actuator）。

## 6. Git 工作流

| 项 | 约定 |
|----|------|
| 主干 | `main`（保护，仅评审合入）+ `develop`（集成交付） |
| 分支 | `feature/M{阶段}-{模块}`、`fix/...`、`docs/...`、`release/v0.x` |
| 提交 | Conventional Commits：`feat(app): 新增错题本列表接口` / `fix(web): 计时器跨页暂停` / `docs(04): 补充 SSE 协议` |
| 评审 | 合入 develop 需自测清单（§8）+ 文档同步检查 |
| 版本 | git tag `v0.x.0` 对应里程碑（§9）；文档独立版本号在各文档变更记录维护 |
| 禁止 | 提交 .env、target/、node_modules、unpackage/、大媒体文件 |

## 7. 编码规范

### 7.1 Java / Spring Boot

- 分层职责见 02 §4.1：controller 不写业务、service 不拼 JSON、mapper 不做业务判断。
- 命名：`XxxController` / `XxxServiceImpl` / `XxxMapper` / `XxxDTO(入)` / `XxxVO(出)` / `XxxEntity(表)`；字段 camelCase ↔ snake_case 自动映射。
- 校验：入参 `@Valid` + 注解；错误一律 `BizException(code, msg)` → 全局处理器，禁止 controller try-catch 吞错。
- 事务：写路径 `@Transactional(rollbackFor=Exception.class)`，领域纯逻辑（判分/掌握度）不依赖事务。
- 日志：SLF4J，参数化 `{}`；关键动作 info（userId+action），异常 error 带堆栈；禁止 sout。
- 纯逻辑强制：`service/domain` 包**禁止 import org.springframework.***（M1 加 ArchUnit 或 simple 头检查脚本）。

### 7.2 TypeScript / Vue 3

- `<script setup lang="ts">` + 组合式；禁 any（`unknown` + 收窄），导出类型用 `export type`。
- 命名：组件 PascalCase；composable `useXxx`；store `useXxxStore`；API 模块 `api/xxx.ts` 函数 camelCase。
- 样式：`<style scoped>` + CSS 变量（05 §5）；不写死颜色/文案（文案走 `shared/locales`）。
- 工具链：ESLint（@antfu 或 vue3-recommended）+ Prettier（printWidth 100）+ `vue-tsc --noEmit` typecheck；M1 配置根目录共享 `packages/config`。
- 提交前钩子：`lint-staged`（可选，husky 不强加，CI 兜底）。

### 7.3 接口契约

- 前端只准调 `packages/api-client`，禁止散落 fetch/axios；
- 新接口流程：改 04 文档 → 后端实现 → OpenAPI/手写类型 → api-client → 页面；
- 错误码新增必须登记 04 §3 表。

## 8. 自测清单（每次合入前）

- [ ] `mvn -pl <模块> test` 通过（核心域单测必须绿）
- [ ] `pnpm typecheck && pnpm lint` 通过
- [ ] 本端口表启动无冲突（`pnpm ports:check`）
- [ ] 未配置第三方 Key 时相关入口**隐藏**而非报错（01 可降级原则）
- [ ] 涉及文档变更已升版本 + 变更记录
- [ ] 未提交 .env/产物/敏感 Key
