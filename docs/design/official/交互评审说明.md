## 1. 本次稿件的范围

本稿沿用已确认的品牌「数源 MathOrigin」、数理理性视觉、蓝紫重点色、衬线标题及亮暗双主题。它提供**六个可交互视图**：首页、系统课程路径、正弦函数词条、勾股定理公式、数学年表、学习工具。首页按原定的十二模块组织，展示官网从认识产品到阅读公开内容再到进入学习端的完整方向。其余五条路径和其他资源详情目前以“待制作”反馈标注，不能拿此稿当作六区 40+ 页型的全站高保真完成证据。

官网正式产品仍按 13 号文档的六区站点图建设。`apps/official` 尚未初始化页面，21 号状态表的 O-00～O-05 仍为未完成；此文件是**本地设计原型**，不连接后台、注册、判分、订阅、服务状态或实际下载。

### 两条关键旅程

1. **初次到访**：Hero → 六路径或三题测验 → 推荐方向 → “学习入口”流程说明 → 学习端设计稿。测验只做本地推荐，不声称真实用户画像或自动建档。
2. **搜索/分享落地**：词条、公式或每日题公开阅读 → 接龙/相关内容 → 场景内 CTA → 保留目标的登录注册流程说明。正式实现须使用 20 号文档 BR-09 的白名单 intent/resumeToken；本地稿只保留当前页面状态，不生成真实 token。

公开知识内容**不设登录墙**。内容页的 CTA 引导学习端的练习、记录与推理互动，不能把公开解析藏在注册之后。

## 3. 视觉与交互说明

- **形态**：12 栏桌面内容区；坐标纸网格只做衬底；蓝紫渐变主要用于主行动按钮、Hero 标记和关键数字。标题使用宋体系，正文用系统黑体。
- **响应式**：桌面使用横向导航和双栏 Hero；窄屏改为全屏分组菜单，卡片收为一栏；年表在平板和手机上排成纵轴；手机画板以 4:3 显示。菜单、搜索、主题与主要入口应保持可见。
- **主题**：首次跟随系统；用户手动切换后记住偏好；系统主题发生变化时，未手动选择的稿件继续跟随。
- **键盘与反馈**：`Ctrl/⌘+K` 或 `/` 打开搜索，方向键与 Enter 选择，Esc 关闭；四卡可用方向键切换；年表节点可用 Enter/空格选取；操作反馈用文字说明，不只靠颜色。
- **动效**：推理链、卡片入场、数字与画板作为局部焦点；系统要求减少动画时，入场动效关闭。正式实现应继续检查对比度、焦点顺序、触控尺寸与读屏标签。

## 4. 内容真实性与发布边界

| 位置 | 评审稿处理 | 正式上线所需依据 |
| --- | --- | --- |
| 首页结构数字 | 只展示已确认的 6 路径、3 内核、4 卡、1 套知识体系 | 若改为题量/公式/词条数，须从已发布内容快照统计，不使用 M7 内容目标冒充现状 |
| 学习场景卡 | 明确标“场景示例”，不署名内测学员 | 用户授权且可追溯的真实案例与引语 |
| 博客、年表、词条历史 | 标示选题/示例；史实与出处待编辑审核 | 已审核的文章与内容快照 |
| Newsletter | 只预览反馈文案，输入邮箱不会提交 | 订阅接口、失败重试、退订与邮件链路 |
| 下载、RSS、服务状态 | 显示规划或待接入，不给假二维码和绿色健康灯 | 正式客户端地址、Feed 与监测数据 |
| 学习 CTA | 弹出目标恢复流程说明，可查看学习端设计稿 | 真正的注册/登录、目标白名单、过期/下架恢复与回访测试 |
