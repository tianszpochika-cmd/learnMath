正弦函数（sine）

概念四卡的公开版：先看它从哪里来，再看它怎么写。

起源
现实
能力地图
抽象阶梯

被现实逼出来的工具

当长度难以直接测量时，可以先研究角度与边长比例。在相似直角三角形中，同一锐角的对边与斜边之比不变；正弦将这一比例表达为角度的函数。

本页是教学动机示例；数学史的具体人物、年代与出处由内容审核后另行发布。

它长在自然里

斜线与高度斜线长度为r，与水平面夹角θ时，高度为r sinθ；影长与塔高则使用正切关系。
理想简谐振动理想单频信号可以用正弦函数描述；复杂信号的分解需要相应条件。
圆周投影匀速圆周运动在坐标轴上的投影呈正弦或余弦变化；并非每种周期现象都是单一正弦。

从生活话到符号，三级台阶

REAL · 现实这个斜坡有多"陡"？影子有多长？
MODEL · 模型对边与斜边的比值——固定锐角下它不变。
SYMBOL · 符号sin θ = 对边/斜边 → 单位圆定义 → 波形。

几何 · tier 1 基础 ✓ 严格证明

勾股定理

别名：毕达哥拉斯定理 · 商高定理 · 直角三角形三边关系

a² + b² = c²∬
⚠ 成立条件：仅适用于直角三角形（∠C = 90°），a、b 为直角边，c 为斜边边长必须为正实数；推广到任意三角形请用余弦定理 a²+b²−2ab·cosC = c²
起源：古埃及丈地 → 毕达哥拉斯学派严格化 → 赵爽弦图（中国独立证明）
S1 · teaser

面积拼图

四个全等直角三角形拼进大正方形——面积守恒是起点。

S2 · teaser

代数整理

2ab 项两边相消，留下 a²+b²=c² 的干净形式。

S3 · teaser

完整五玩 → 学员端

顺逆对照、多解（面积法/相似法/向量法）、预测下一步——注册后深钻。

家族关系

余弦定理（推广）射影定理（特例族）求根公式（配方同源）向量点积形式（等价）

常见错误变形（红笔）

a² + b² = c² 对任意三角形成立

✘ 任意三角形缺了 −2ab·cosC 修正项；C=90° 时 cosC=0 才退化为勾股定理——这正是"推广"的方向。
