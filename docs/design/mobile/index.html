解方程 x²−5x+6=0，并说明每一步的依据。

通读 · 推理链（点步展开三层）
S1 · 工具选择
尝试因式分解：找两数积 6、和 −5
依据：十字相乘法适用（首项系数为1）
为什么想到：常数 6=2×3 且 2+3=5——信号明显
岔路：6 的因数组不合时才转求根公式
S2 · 等价变形
分解为 (x−2)(x−3)=0
依据：乘法分配律逆用（等价变形）
为什么想到：S1 已锁定 2 与 3
岔路：写成 (x+2)(x+3) 是符号错——负号来自"和为负"
S3 · 论证
零因子律：积为 0 则 x=2 或 x=3
依据：整环中无零因子
为什么想到：目标是"解出 x"，降次到一次
岔路：不能两边同除 (x−2)——会丢根！
预测下一步（E2 · 点评双分支）
已知 (x−2)(x−3)=0，下一步该做什么？
A两边同除以 (x−2)
B用零因子律得 x=2 或 3
C展开重新计算
顺逆对照（同色步对齐）
综合法（由因导果）

条件 x²−5x+6 → 十字相乘 → 零因子 → 根

分析法（执果索因）

要 x=? → 需降次 → 需分解 → 需找因数对
