勾股定理

a² + b² = c²
适用于直角三角形；a、b 是直角边，c 是斜边。

完整研习

起源

从直角三角形的边与正方形面积关系理解这一命题；史实出处未补齐时不作具体年代断言。

符号表

a、b：正实数，直角边长度；c：正实数，斜边长度。三条边使用同一长度单位。

推导链

边长 a+b 的正方形由四个全等直角三角形和中间边长 c 的正方形组成。

(a+b)² = 4×ab/2 + c² → a²+2ab+b²=2ab+c² → a²+b²=c²。

完整条件与误用边界

夹角必须为90°，且c为对该角的边。一般三角形须使用余弦定理；不能直接写 a+b=c。

应用

测量矩形对角线、计算平面上两点之间的距离。

家族关系

余弦定理在夹角90°时得到此式。三维空间距离公式可以连续使用两次勾股定理得到。

变形族

c=√(a²+b²)；在c>b>0时，a=√(c²−b²)。平方根取正值，因为这里表示长度。

从边长到距离

先确认三角形是直角三角形，再用两条直角边计算斜边。
