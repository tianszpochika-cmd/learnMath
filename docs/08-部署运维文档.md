## 1. 环境清单

| 环境 | 机器 | 用途 |
|------|------|------|
| dev | 开发机（大内存） | 本文 §2 |
| prod | 单机云服务器（建议 4C8G 起，MySQL 同机） | 本文 §3-§6 |

| 生产基线 | 版本 |
|---------|------|
| OS | Linux x64（Ubuntu 22.04+/Debian 12） |
| Docker + Compose | ≥28.0 / ≥2.40 |
| JDK 运行时 | eclipse-temurin:25-jre（镜像内） |
| MySQL / Redis | 8.x / 8.x（容器） |
| Nginx | ≥1.24（证书、静态、反代） |

## 2. 开发环境（dev）

```bash
docker compose up -d            # learnmath-mysql:13307 + learnmath-redis:16380
# 迁移：按序执行 server/src/main/resources/db/migration/V*.sql
# 后端：mvn spring-boot:run -pl learn-app-api / learn-admin-api
# 前端：pnpm dev:web|admin|official  pnpm dev:uniapp:h5
```

- 端口以 06 §4 登记表为准；启动前 `pnpm ports:check`。
- compose 项目名 `learnmath`、容器前缀 `learnmath-`，与 cloudstudy（`yuxuexing-local`）天然隔离，可同机并存。
- 本地数据卷挂载 `./docker-data/`（已 gitignore），重建容器不丢库。

## 3. 生产拓扑（单机）

```
                    Internet（HTTPS :443）
                          │
                        Nginx
        ┌─────────┬───────┼────────┬─────────────┐
     /            /admin   /api/app   /api/admin    /h5 (uniapp)
  official静态   web静态   →127.0.0.1:8080  :8081   静态（H5产物）
  + Nuxt SSR节点(:3000 本机回环)
                          │
        ┌─────────────────┴──────────────────┐
        │ docker compose (project: learnmath) │
        │  ├ app-api   (temurin-25-jre)  8080 │
        │  ├ admin-api (temurin-25-jre)  8081 │
        │  ├ mysql 8   仅容器网，宿主127.0.0.1:13307 │
        │  ├ redis 8   仅容器网，宿主127.0.0.1:16380 │
        │  └ nginx（也可宿主安装，二选一）        │
        └────────────────────────────────────┘
   volumes: mysql-data / redis-data / app-logs / uploads
```

- **域名规划**：`www.xxxx.com`（官网+Web SPA 同域）、`admin.xxxx.com`（管理端，IP 白名单可选）、API 走同域路径反代（避免 CORS）；uniapp H5 用主域 `/h5/`。
- 管理端可加 Nginx `allow/deny` 或 Basic Auth 双保险；全站 HTTPS（certbot/ACME）。
- 小程序/App 要求 HTTPS + 备案域名（在小程序后台配置 request 合法域名）。

## 4. 构建与镜像

### 4.1 后端 Dockerfile（每模块，多阶段）

```dockerfile
# build
FROM maven:3.9-eclipse-temurin-25 AS build
WORKDIR /app
COPY pom.xml . && COPY learn-app-api/pom.xml learn-app-api/
RUN mvn -q -pl learn-app-api -am dependency:go-offline   # 层缓存
COPY . .
RUN mvn -q -pl learn-app-api -am -DskipTests package

# run
FROM eclipse-temurin:25-jre
WORKDIR /app
COPY --from=build /app/learn-app-api/target/*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java","-XX:MaxRAMPercentage=75","-Duser.timezone=Asia/Shanghai","-jar","app.jar"]
```

（admin-api 同构，8081；也可单镜像双 jar 用 profile 切换——一期推荐两镜像，独立发布。）

### 4.2 前端产物

| 端 | 命令 | 产物 | 落点 |
|----|------|------|------|
| web | `pnpm build:web` | apps/web/dist | nginx `/` |
| admin | `pnpm build:admin` | apps/admin/dist | nginx `/admin` |
| official | `pnpm build:official` | apps/official/.output（Nitro node server 或 SSG） | SSR 用 node/pm2；**SEO 必要 → SSR 常驻**，静态资源 nginx 直出 |
| uniapp | `pnpm build:uniapp:h5` | apps/uniapp/dist/build/h5 | nginx `/h5/` |

`docker-compose.prod.yml` 汇总：app-api、admin-api、mysql、redis、official-ssr（**node:20-alpine** 跑 Nitro —— S1 基线 Nuxt 3.21 运行于 Node 20.19.5，与 cloudstudy 同栈）、nginx。

## 5. 配置与密钥管理

| 层 | 内容 |
|----|------|
| git | 仅 `.env.example`（键名+注释） |
| 服务器 | `.env`（chmod 600）：DB 密码、JWT 密钥（**两域不同**）、LLM/SMS/微信 Key |
| profile | `application.yml`（默认）+ `application-prod.yml`（由环境变量注入 `SPRING_*` / 自定义 `${DB_PASSWORD}`） |
| 启动注入 | compose `env_file: .env`；JVM 时区、日志级别参数 |

必改密钥清单：`DB_PASSWORD`、`JWT_APP_SECRET`、`JWT_ADMIN_SECRET`、`LLM_API_KEY`（可空=降级）、`SMS_*`（可空）、`WECHAT_*`（可空）、`UPLOAD_DIR`。

## 6. 上线检查清单

**部署前**
- [ ] 发版 tag 对应回归门槛（07 §7）全过
- [ ] `.env` 密钥为生产值且 600；仓库 gitleaks 无泄漏

- [ ] 镜像版本固定（勿用 `latest`），保留上一版本镜像可 5 分钟回滚

**部署中**
- [ ] `docker compose -f docker-compose.prod.yml up -d` 健康检查全 green
- [ ] `GET /actuator/health` 200（app/admin）
- [ ] Nginx：HTTPS 证书、`/api` 反代头（X-Forwarded-Proto）、gzip

**部署后验证**

- [ ] 监控出数（§8）、日志无 ERROR 刷屏

## 7. 备份与恢复

| 对象 | 策略 |
|------|------|
| MySQL | 每日 03:30 `mysqldump --single-transaction` 全库 → `backups/learnmath_$(date).sql.gz`，保留 **14 天**；周全量+binlog 可选（量大后） |
| Redis | 不备份（纯缓存/会话，可丢弃；丢后用户需重登） |
| uploads | 目录同步（rsync/对象存储）每日 |
| 恢复演练 | 每季度恢复到临时库验证 dump 完整性 |

```bash
# 备份 cron 示例
0 3 * * * docker exec learnmath-mysql sh -c 'exec mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" learnmath' | gzip > /data/backups/learnmath_$(date +\%F).sql.gz
```

迁移版本管理：`db/migration/V*.sql` + `db_schema_version` 表（或 Flyway）；**先备份 → 执行 → 冒烟**，迁移只前进不手改历史文件。

## 8. 日志与监控

| 项 | 方案（一期） |
|----|--------------|
| 应用日志 | logback → `/data/logs/{app}.log`，按天滚动保留 14 天；JSON 行格式便于采集 |
| 访问日志 | nginx access log 滚动 |
| 健康 | `/actuator/health` + 外部 Uptime Kuma/宝塔定时探测（可选） |
| 指标预留 | actuator + micrometer → 后续 Prometheus（03 端口段 28xxx 系列避开监控口） |
| 告警 | 一期：进程存活 + 磁盘 + MySQL 主机探测；异常码 5000 突增看日志 |
| 审计 | `admin_op_log` 表留存 ≥180 天 |

## 9. 扩容与演进路径

1. **单机瓶颈**：先纵向（8C16G）+ MySQL 读写分离预留；静态上 CDN；
2. **拆分触发点**：AI SSE 长连接多 → app-api 横向扩容（无状态，LB 即可）；作答判分峰值 → 独立 worker 模块（02 领域包可直接搬）；
3. **不提前做**：Kafka/微服务/分库分表 —— cloudstudy 的架构是 16 服务的答案，不是本项目一期的答案。

## 10. 故障处置速查

| 症状 | 排查 |
|------|------|
| 前端 502 | 容器健康？→ app-api 日志 → 端口占用 |
| 登录全挂 | JWT_SECRET 变更导致旧 token 失效？Redis 挂了（refresh 白名单）？ |
| 迁移失败 | db_schema_version 记录、最近 dump 回滚、勿手工改 V*.sql |
| AI 报 3100 | 预期降级：查 configs.ai 开关/Key；3102 查上游与限流 |
| 磁盘满 | logs/backups/docker prune 顺序处理 |
| 小程序请求失败 | 合法域名/证书链/备案 核对 |
