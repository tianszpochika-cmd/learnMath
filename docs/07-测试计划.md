## 1. 测试策略（分层）

| 层 | 工具 | 范围 | 执行时机 |
|----|------|------|---------|
| 单元测试 | JUnit 5 + AssertJ；Vitest（前端纯逻辑） | **领域纯逻辑全覆盖**：判分、掌握度、解锁 DSL、SRS、积分成就、无环校验 | 每次提交 |
| 集成测试 | @SpringBootTest + Testcontainers(MySQL/Redis) | Mapper SQL、事务、限流、JWT 签发校验、SSE 帧 | 每次合入 develop |
| 接口契约 | SpringMockMvc + 前端 schema 校验（可选 spector） | 04 全量接口的响应结构/错误码 | 每次合入 |
| 组件测试 | Vitest + Vue Test Utils | QuestionCard 三态、AnswerSheet、SSE 解析器 | 每次合入 |
| E2E | Playwright | 关键用户旅程（§4.3），覆盖 web（主）+ admin | 每日/发版前 |
| 移动端 | uniapp H5 跑 Playwright 冒烟 + 微信开发者工具手工清单 | 核心 5 旅程的 H5 复刻 | M6 |
| 性能 | k6 或 wrt 压测脚本 | 04 热点接口 P95（01 §9） | M6、上线前 |
| 安全 | 手工清单 + 依赖扫描（`pnpm audit`、OWASP ZAP 基础扫描） | §5 清单 | M6、上线前 |

覆盖率目标：`service/domain` 行覆盖 **≥90%**；后端整体 ≥70%；核心前端逻辑（SSE/判分展示）≥80%。CI 不达标卡合并（M1 配置）。

## 2. 环境与数据

| 项 | 约定 |
|----|------|
| 测试库 | Testcontainers 独立 MySQL/Redis（不污染 dev 库）；无 Docker 时降级 H2 需标注 SQL 兼容风险 |

## 3. 关键用例（优先级 P0/P1）

### 3.1 判分引擎（P0）

| 用例 | 输入 | 期望 |
|------|------|------|
| 多选顺序无关 | 答案 ABD，用户 DBA | correct |
| 千分位/全角 | 答案 1000，用户 `１，０００` | correct |
| 分数等价 | 答案 0.5，用户 `1/2`、`½` | correct |
| 多可接受答案 | 答案 `x=1\|1`，用户 `1` | correct |
| 数值容差 | 答案 3.14159，用户 3.1416（容差关） | incorrect；开容差→correct |
| 多空部分对 | 2 空对 1 空 | score=50%（按空比例，配置可改全对才得分） |
| 解答题自评 | 提交后 is_correct=NULL → self-assess 三态 | 落库且计入掌握度（不会=0 分） |

### 3.2 图谱/解锁/掌握度（P0）

| 用例 | 期望 |
|------|------|
| 加边成环（A→B 已存在，再加 B→A） | 3310，事务回滚，边表无变化 |
| 前置未达 mastery<80 进入节点 | 3311；=80 放行 |
| P4 阶梯：正确率 80% 且 ≥10 题 | 解锁下一难度；差 1 题不解锁（minCount 边界） |
| 掌握度难度加权 | 同正确率下 L5 题得分 > L1 |
| 14 天未练 decay | 固定时钟 +15 天，批量任务后 score 下降 |
| 跨路径共享 | P1 做题后，P2 图谱该节点颜色变化、P4 阶梯计数变化 |
| DSL 组合 allOf/anyOf | 嵌套求值表驱动测试 ≥10 组 |

### 3.4 路径/计划/游戏化（P0/P1）

| 用例 | 期望 |
|------|------|
| 打卡重复提交 | 幂等，3501 不重复记积分 |
| 跨零点打卡（23:59:58 提交） | 归属当日；00:00 后为次日（固定时钟） |
| 补签积分不足 | 3502 |

| 计划动态调整 | 连 3 天完成→下周任务量+1；连 3 天未完成→插入先修复测 |
| P6 星数不足进 Boss | 3311；星数达标放行 |

### 3.6 学习引擎（v1.1 增补 · P0）

| 用例 | 期望 |
|------|------|
| 深钻链渲染 | 四要素齐全、DAG 无孤步（管理端保存时校验）；ai_draft 角标正确 |
| 预测点评分支 | 答对→explain_right；答错→explain_wrong；**首次做题强制教学一次、之后可跳**（E2） |
| 顺逆对照对齐 | 同 seq 步同色联动；分析法缺步时显示"此解法无逆推标注"降级 |
| 断链落库 | 错题（有链）→ broken_step_seq+break_kind 非空；无链题→退回传统错因标签 |
| 补救直达 | 断步 warrant_nodes → 图谱节点跳转 + 动机训练题推荐 2 道 |
| 回代跳过（E4） | skip=true 允许完成，backsolve_skipped=1；**不阻断完成**；下次同类题仅文案提醒一次 |
| 四卡降级（E3） | status<3 → draft 角标 + 部分展示；缺卡不报错 |
| 转译校验（E1） | 非法链（步数<2/seq 断/warrant 空）→ 打回重试 2 次→人工队列；学员端仅见 curated/带标 ai_draft |
| 考试防作弊 | 作答中调 /deepdive → 拒绝；判分后开放 |
| 苏格拉底/直讲切换（E5） | 默认 socratic 帧流；切 direct 上下文不丢（同 conversation） |
