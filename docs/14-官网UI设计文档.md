## 1. 设计原则（v2.0 增补）

| 原则 | 含义 |
|------|------|
| 灵魂可视化 | Hero 推理链动图是最大资产，页面元素为其让路 |
| 精确即美感 | 12 栏栅格、4pt 对齐 |
| 渐变是标点 | U2 纪律在亮/暗两态同样生效 |
| 一屏一动效 | 动效只在注意力焦点 |
| 快即体验 | LCP <1.8s；衬线子集、动图延迟、系统正文字体零下载 |
| **内容卡即产品** 🆕 | 词条/公式/每日题卡片用学员端同款语义色与排版（所见=所得），降低注册后认知成本 |
| **暗色一等公民** 🆕 | 双主题同步设计，不允许"只亮后补暗"的组件合入 |

### 2.3 纹理与渐变纪律

| 元素 | 规格 |
|------|------|
| 坐标纸网格 | 32px 细线 `rgba(47,107,255,.05)`（暗色 `.06` 蓝紫调）；每屏 ≤1 处底纹 |

| **渐变合法位** | ✅ 主 CTA、Hero glow、背书数字、眉题圆点、进度条、测验结果条 ｜ ❌ 背景、正文、卡片底、同元素叠分类色 |

### 2.4 暗色 Token（V3 · `:root[data-theme="dark"]` 翻转表）

```css
--bg-page:#0B1220; --bg-card:#111827; --bg-alt:#0F172A; --line:#1E293B;
--ink-900:#F8FAFC; /* 标题反白 */ --ink-700:#CBD5E1; --ink-500:#94A3B8; --ink-400:#64748B;
--grad-action: linear-gradient(135deg,#5B87FF 0%,#9B6BFF 100%);  /* 亮度 +10% */
--grad-text:   linear-gradient(120deg,#7DA3FF,#A78BFA);
--bg-deep:#060B16;              /* 深底区更深一级 */
--shadow-card:0 1px 2px rgba(0,0,0,.4)；--shadow-lift:0 12px 32px -8px rgba(91,135,255,.35)；
--ok/--warn/--bad: 不变（语义色暗底均 ≥4.5:1，已验）；
网格纹: rgba(125,158,255,.04)；Hero 动图 glow 提亮 15%；图片区加深色蒙版 12% 保证浮字可读。
```

**切换机制（ThemeToggle）**：导航右侧 🌞/🌙 按钮 → 点击在 light/dark 间切换 → 写 `localStorage.theme`；**首载默认 = `prefers-color-scheme`**（无 stored 值时）；`<head>` inline script 同步 `data-theme` **防闪烁**（原型已实装）。

## 4. 全局框架（v2.0 升级）

### 4.1 顶部导航 + Mega-Menu

```
[π] 数源 MathOrigin | 产品 ▾  资源 ▾  博客  下载  关于        [🔍⌘K] [🌞] [登录] [免费开始]
```

| 规格 | 说明 |
|------|------|
| 栏高 | 64px → 滚动 56px，毛玻璃 blur(12)（v1 继承） |
| **产品 ▾ mega** | 三列：六路径（分类色点×6）｜ 功能（8 详情入口双列）｜ 价格/更新日志/路线图 |
| **资源 ▾ mega** | 词条百科 ｜ 公式馆 ｜ 每日一题（带"今日"角标）｜ 数学年表 ｜ 学习工具 ｜ FAQ/帮助 |
| 交互 | hover 200ms 展开 + focus 键盘可达 + 点击区外/Esc 关；移动端 → 全屏抽屉（衬线大字分组） |
| 右侧 | ⌘K 搜索按钮（显示 `⌘K` 键帽）+ ThemeToggle + 登录 + 主 CTA（渐变） |

### 4.2 ⌘K 命令面板（CmdKPalette）

- 唤起：`Ctrl/⌘+K`、点击搜索钮、`/`（非输入态）；关闭：Esc / 点遮罩；
- 结构：居中浮层（max-w 640、顶部输入框、结果分组：词条/公式/文章/路径/帮助，每行图标+标题+一句摘要）；
- 行为：防抖 200ms → `GET /explore/search`（原型为本地 mock 索引）；↑↓ 选择、↵ 跳转；空态推荐词 chips；
- 视觉：亮/暗自适应、选中行主蓝 8% 底、`Enter` 提示角标。

### 4.3 滚动进度条（ScrollProgress）

顶部 3px 渐变条（fixed），宽度=滚动百分比，`transform:scaleX` 实现（零重排）；文章页复用为阅读进度。

### 4.4 页脚（升级）

5 列：品牌（logo+理念+**RSS 图标链接**）｜ 产品 ｜ **资源（词条/公式/每日题/年表/工具/FAQ）** ｜ 公司（关于/宣言/案例/媒体/联系）｜ 订阅（Newsletter 迷你表单）；
底行：© 2026 数源 MathOrigin · ICP 占位 · legal×2 · **状态灯徽章（/status 链）**。

## 9. 响应式与无障碍

| 断点 | 关键变化 |
|------|---------|
| ≥1280 | 12 栏全量 |
| 1024-1279 | Hero 6:6；mega 缩列距 |
