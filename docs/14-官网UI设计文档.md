## 0. 已确认决策（U1-U4 · 需求方拍板）

| # | 决策点 | 结论 |
|---|--------|------|
| U1 | 视觉风格 | **数理理性风**：坐标纸网格底纹、精确对齐、公式即图形、推理链即叙事 |
| U2 | 色彩策略 | **蓝紫渐变潮流风**：CTA/Hero 高亮/关键数字用 `#4F7BFF→#8B5CF6` 渐变（克制边界见 §2.3） |
| U3 | 标题字体 | **全衬线标题**：所有 H1-H4 用中文宋体系（学术编辑感），正文黑体；加载方案见 §3 |
| U4 | 交付形式 | **14 号规范文档 + 单文件 HTML 原型** |

> **调和原则**：底子是"坐标纸 + 衬线"= 学术的骨；渐变只出现在**可点击物与关键数据**上 = 潮流的皮。两者不打架：一屏渐变元素 ≤2 处、渐变永不铺满背景、渐变上不压长正文。

## 1. 设计原则（官网特化）

| 原则 | 含义 |
|------|------|
| 灵魂可视化 | Hero 推理链动图（13 §5.2）是最大视觉资产，页面其余元素为其让路 |
| 精确即美感 | 12 栏栅格、4pt 对齐、基线严格 —— 数学产品的"讲道理"体现在像素上 |
| 渐变是标点 | U2 渐变仅作强调（CTA/数字/眉题点），不做面 |
| 一屏一动效 | 动效只在注意力焦点（Hero、数字滚动、卡片 hover），拒绝全屏乱动 |
| 快即体验 | 首屏 LCP<1.8s：衬线子集化、动图延迟、系统正文字体零下载 |

## 2. Design Tokens（终版）

### 2.1 色彩

```css
/* 主色板 */
--c-primary-50:#EEF4FF; --c-primary-100:#E0EBFF;
--c-primary:#2F6BFF;    --c-primary-600:#1E4FD6; --c-primary-700:#173DB0;
--c-violet:#8B5CF6;     /* 渐变终点 */
--c-gold:#FFB020;       /* 点缀：数字/成就 */

/* U2 渐变（唯二合法渐变） */
--grad-action: linear-gradient(135deg,#4F7BFF 0%,#8B5CF6 100%); /* CTA */
--grad-text:   linear-gradient(120deg,#4F7BFF,#8B5CF6);          /* 关键数字/词 clip 文字 */

/* 中性 */
--ink-900:#0F172A; --ink-700:#334155; --ink-500:#64748B; --ink-400:#94A3B8;
--bg-page:#F8FAFC; --bg-card:#FFFFFF; --bg-alt:#F1F5F9; --bg-deep:#0B1220;
--line:#E2E8F0;

/* 语义（与图谱四档同源，05 §5） */
--ok:#22C55E; --warn:#F59E0B; --bad:#EF4444;

/* 六路径分类色（U 决策沿 G2：仅卡片色条/徽章，不铺面） */
--p1:#2F6BFF; --p2:#10B981; --p3:#8B5CF6; --p4:#F59E0B; --p5:#EC4899; --p6:#F97316;
```

**渐变使用边界（U2 纪律）**：✅ 主 CTA、Hero 动图高亮、背书大数字、章节眉题小圆点、进度条 ｜ ❌ 大面积背景、正文文字、卡片底色、与分类色同时出现在同一元素。

### 2.2 字体 / 间距 / 形状 / 阴影

```css
--font-serif: "Noto Serif SC","Source Han Serif SC","Songti SC","SimSun",serif; /* U3 标题 */
--font-sans:  system-ui,-apple-system,"PingFang SC","HarmonyOS Sans","Microsoft YaHei",sans-serif; /* 正文零下载 */

--fs-h1: clamp(40px, 5.6vw, 68px);  /* 衬线 700，行高 1.18，字距 .01em */
--fs-h2: clamp(28px, 3.2vw, 40px);  /* 衬线 700 */
--fs-h3: 22px;                      /* 衬线 600 */
--fs-body: 16px/1.8;  --fs-sm: 14px/1.7;  /* 黑体 */
--fs-num: clamp(40px,5vw,64px);     /* tabular-nums 800 */

--sp: 4px 基准（8/12/16/24/32/48/64/96）; --container:1200px; --gutter:24px;
--r-card:16px; --r-btn:12px; --r-tag:8px;
--shadow-card: 0 1px 2px rgba(15,23,42,.06);
--shadow-lift: 0 12px 32px -8px rgba(79,123,255,.22);   /* hover，带一点渐变色相 */
--ease: cubic-bezier(.22,1,.36,1);
```

### 2.3 纹理与图形语言

| 元素 | 规格 |
|------|------|
| 坐标纸网格 | `repeating-linear-gradient` 32px 细线，`rgba(47,107,255,.05)`；仅 Hero/方法论/眉题区，**每屏 ≤1 处底纹** |
| 几何装饰 | SVG 细线（1.5px，`--line` 色）：圆规弧、坐标轴、函数曲线剪影；透明度 ≤8%，绝不压正文 |
| 公式图形 | KaTeX/Unicode 公式作装饰：页角大符号（∑/∫/π，6-8% 透明度）、区块编号 `§` + 公式记号 |
| 图标 | 线性 1.5px 图标集（路径六图标自绘：书/网/表/阶/卷/旗），24px 网格 |

## 3. U3 全衬线标题 —— 加载与降级方案

| 场景 | 方案 |
|------|------|
| 生产 | **自托管 Noto Serif SC woff2 子集**（构建期按标题用字集切片，目标首包 ≤200KB；`font-display:swap`），备选：中文子集化 CDN 服务 |
| 首屏 | H1 用字纳入 preload 子集；未就绪时 fallback 宋体（SimSun/Source Han Serif），**无闪烁白屏**（swap） |
| 原型 | 系统宋体栈 + 可选 jsDelivr `@fontsource/noto-serif-sc`（断网自动回退宋体，见原型文件） |
| 使用域 | H1-H4、路径页大标题、引用金句、数字（800 权重可用衬线数字或 tabular 黑体二选一：**定稿=黑体数字**，理由：滚动计数稳定性） |
| 禁用域 | 正文、按钮文字、表单、导航（黑体），避免可读性与渲染负担 |

## 4. 全局框架

### 4.1 顶部导航（64px → 滚动 56px，`backdrop-filter: blur(12px)` + 白 85%）

```
[π 徽标] 数源 MathOrigin   路径 ▾  功能  下载  博客  关于        [登录] [免费开始]←渐变
```
- 下拉「路径」：六路径双列菜单，每项带分类色点；
- 移动端：汉堡 → 全屏抽屉（衬线大字菜单）；
- 焦点态：2px 主蓝 focus ring（offset 2），全站键盘可达。

### 4.2 页脚

4 列（产品/六路径/资源/关于）+ 左侧品牌区（logo + 一句理念 + 公众号码）+ 底行：© 2026 数源 MathOrigin · ICP 备案号占位 · 隐私政策/用户协议（/legal）· 友情链接位（预留）。深底 `--bg-deep`，链接 hover 主蓝。

## 7. 组件规格（开发实现清单 · 与原型一一对应）

| 组件 | 规格要点 |
|------|---------|
| `Btn` | primary=**渐变底白字**（hover 亮度+8% 上浮 1px，active 下压）；secondary=描边 `--ink-400`；ghost=文字链；尺寸 sm36/md44/**lg48**；圆角 12 |
| `PathCard` | 见 §5-2；整卡可点，`aria-label` 含路径名 |
| `DemoCard` | 示意区 16:10（占位=网格+大符号）；hover 播放 CSS loop |
| `StatNumber` | IntersectionObserver 触发 count-up（1.2s ease-out，tabular 防抖），渐变 clip 数字 |
| `SectionHeader` | 眉题 = 8px 渐变圆点 + 14px 字距 0.08em 小字；H2 衬线；副题 `--ink-500` |
| `FaqAccordion` | grid-rows 0fr→1fr 过渡 260ms |
| `BlogCard` / `QuoteCard` / `BadgeChip` | 卡片统一 `--shadow-card` → hover `--shadow-lift` |
| `FormulaDecor` | 角落公式符号，`aria-hidden` |
| 状态 | loading=骨架（网格闪烁）；focus=2px ring；图片=灰底占位 |

**入场动效**：`fade-up 500ms var(--ease)`，同屏 stagger 80ms，仅触发一次；`prefers-reduced-motion` 全部降为瞬时显示。

## 8. 响应式与无障碍

| 断点 | 布局 |
|------|------|
| ≥1280 | 12 栏，container 1200 |
| 1024-1279 | 12 栏收 gutter；Hero 6:6 |
| 768-1023 | 8 栏；路径卡 2×3；三内核横滑 |
| <768 | 单栏；Hero 图下文上（动图高减为 300px）；导航抽屉；下载区纵向堆叠 |

无障碍：正文对比度 ≥AA（`--ink-500` on `--bg-page` 已验 4.6:1）；H1 唯一；装饰公式/网格 `aria-hidden`；动效可关（reduced-motion）；全部交互键盘可达；语义 `<section aria-labelledby>`。

## 9. 性能预算（对齐 13 §5.2）

LCP <1.8s ｜ 渐变零成本（CSS）｜ 衬线子集 ≤200KB（preload H1 用字）｜ Hero 动图延迟加载 ≤200KB ｜ 网格背景纯 CSS ｜ 第三方 0 依赖（原型除外）。
