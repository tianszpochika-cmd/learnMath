## 1. 定位

> **公式不是一行字，是被压缩起来的一次完整推理。**
> `E=mc²` 背下来只需要 3 秒，但它凭什么成立（推导）、什么时候是死的（成立条件）、从哪里来（起源）、能去哪（应用）——公式馆把这些重新展开，让"背公式"变成"懂公式"。

| 内核 | 对象 | 展开方式 |
|------|------|---------|
| 内核一（10） | 题 | 推理链五玩 |
| 内核二（10） | 概念 | 四卡 + 应用五步 |
| **内核三（本文）** | **公式** | **起源 + 推导链 + 推理范围 + 应用范围 + 家族关系** |

三内核共享同一套基建：**推理链模型（reasoning_step）、AI 起草+审核生产流、断链评价、苏格拉底 AI**。

## 2. 对象模型

### 2.1 formula（公式本体）

| 字段 | 说明 |
|------|------|
| name / alias | 正名 + 别名集（勾股定理 = 毕达哥拉斯定理 = 商高定理 → **别名索引是"题面可点"的匹配键**） |
| latex | 展示式（KaTeX 渲染；题面命中 alias/latex 规范形即建联） |
| domain | 领域分卷：算术/代数/几何/三角/数列/概率统计/微积分/线性代数/复变/数论/…（公式馆导航骨架） |
| tier | 难度分卷 1 基础 → 5 研究级（"从最简单到前沿"的纵轴） |
| **proof_status** | **1 严格证明 2 推导确立 3 经验拟合 4 猜想未证**（F3；3/4 显示醒目标注：黎曼猜想=4、素数分布近似=3） |
| origin | 起源：谁/何时/被什么现实问题逼出来（海伦公式→古埃及丈量土地） |
| applications | 应用范围：能解决哪类问题（文字 + 现实域标签引用） |
| memory_hook | 记忆/直观钩子（口诀、几何图像、物理图景） |
| variants | JSON：`legal_forms[]` 合法变形 + `error_forms[]` **常见错误形式**（红笔：sin(A+B)=sinA+sinB ✗ 及为什么） |
| node_refs / rel 表 | 挂知识图谱节点（formula_node_rel） |
| quality | **1 curated 2 ai_draft**（F2，同 E1 标注体系） |
| status | 草稿/待审/上架 |

### 2.2 formula_symbol（符号表）

`formula_id、symbol、meaning、range_note（取值范围：n∈ℕ、θ≠π/2+kπ…）、sort` —— 看懂式子里每个字母。

### 2.3 formula_relation（家族关系 · F4）

`from_id、to_id、rel_type、note`：

| rel_type | 语义 | 例 |
|----------|------|-----|
| 1 推广 | A 是 B 的一般化 | 勾股 → 余弦定理 |
| 2 特例 | A 是 B 的特殊化 | 1+1 = 均值不等式 n=2 |
| 3 等价 | 同一事实的不同表述 | 均值不等式 ↔ 基本不等式 |
| 4 逆命题 | 反向是否成立（note 标真/假） | 面积相等 ⇏ 全等 |
| 5 可组合 | 可联用产生新推导 | 泰勒 ↔ 欧拉公式 |
| 6 常用搭配 | 解题中固定搭档 | 求导 ↔ 极值判定 |

展示 = 关系列表（可跳）+ **家族局部网图**（复用 GraphView，以当前公式为心一跳邻域）。

### 2.4 推导链复用（关键复用点）

`solution_path` 增加 `subject_type（1题目 2公式）+ subject_id` —— **公式详情的"推导" Tab 直接复用内核一的推理链与五玩**（每步四要素、顺逆对照、预测、AI 苏格拉底全部可用），从更基本的公式/公理层层上推。

## 4. 页面结构

```
/formulas               公式馆首页：领域分卷横向导航 + tier 纵向分层 + 搜索(正名/别名) 
                        + proof_status 筛选 + 收藏榜/最近上新
/formulas/:id           公式详情
    头部（一屏）：式子大图 + 名称/别名 + tier·domain·proof_status 角标 + [★收藏] [做道题]
                  +【成立条件红色高亮条】（如 "要求 b≠0；n 为正整数"——先于一切内容看到）
    Tab: 起源 ｜ 符号 ｜ 推导链(五玩复用) ｜ 成立条件与边界 ｜ 应用 ｜ 关系(F4 列表+局部网图) ｜ 变形族
```

- **公式卡抽屉（FormulaCardDrawer）**：题面/深钻/图谱内唤起的轻量版 —— 式子+条件红条+三行摘要（起源一句/能干什么/何时不能用）+ [展开完整页]；
- 移动端（uniapp）：抽屉降级全屏浮层；网图降级家族列表。

## 5. 功能链 L12 公式研习链 + 交互流 I9

### L12（进 09 第一部分编号序列）

**入口四路**：公式馆首页浏览/搜索 ｜ **题面公式点击（F1）** ｜ 图谱节点详情 ｜ 深钻依据引用。

| # | 步骤 |
|---|------|
| 1 | [用户] 任一入口 → 公式卡（头部一屏：式子 + **条件红条** + 角标 proof_status/tier） |
| 2 | [用户] 分层研习 Tab 序：起源（为什么有它）→ 符号（看懂）→ **推导链（凭什么，五玩复用）** → 成立条件与边界（**何时不能用**）→ 应用（干什么）→ 关系网（家族）→ 变形族（怎么变不错） |
| 3 | [系统] 关系跳转、图谱跳转、深钻互跳全部保持上下文（可返回原位） |
| 4 | [用户] [做道题] → **公式小练三型（F5）**：① 条件判断 ② 变形识别（合法 vs 致命错误）③ 应用匹配（现实问题选公式） |
| 5 | [系统] 小练 = 标准作答流（L3）：判分、错题入本、**断链复用**（错在"条件"步 → break_kind=1 缺依据）、小练题挂 `question.formula_id` |
| 6 | [用户] ★收藏 → 复习流（SRS due 提醒）；周报「数学与世界」可推公式起源故事 |
| 7 | [运营] 管理端生产（F2）：批量 AI 起草（符号/条件/起源/应用）+ 推导链走 E1 转译 → 审核队列 → curator 上架；未审核公式 C 端不可见 |

**异常**：alias 未收录→灰态（①）；推导链缺失→"该公式推导整理中"占位（quality 角标不误导）；proof_status=4→头部分区标注"尚未证明"防误当定理使用；小练题不足 3 型→缺的型按钮禁用。

### I9（进 09 第二部分）

```
入口示例（题面联动）：作答页读题 → 题干中 "余弦定理" 三个字/LaTeX 底部点线 → hover 预览卡
 → 点击 → FormulaCardDrawer 右侧滑出：式子 + 红条"需已知两边及其夹角" + 摘要三行
 → [展开完整页] → /formulas/:id → Tab: 推导链 → ModeTabs 五玩（复用 I8 全套交互）
 → 关系 Tab → 家族列表 + 局部网图 → 点"勾股定理（特例）" → 详情页（面包屑可回）
 → [做道题] → 小练三型 → 错在条件判断 → 断链"缺依据·成立条件" → 补救直达该公式条件 Tab
 ⚠ 未收录公式：灰态+tooltip，点击不报错
 ⚠ 考试中：公式卡可看（查阅性质），但小练入口隐藏（防借练习刷题面）
```

## 6. 公式小练三型规格（F5 · 挂 L3/断链）

| 型 | 题型复用 | 判分 | 断链映射 |
|----|---------|------|---------|
| ① 条件判断 | 单选/多选（"哪种情形不能用"） | 集合相等（复用判分引擎） | 错 → `break_kind=1 缺依据（成立条件）` |
| ② 变形识别 | 多选（选出全部合法变形 / 指出致命错误） | 集合相等 + error_forms 对照 | 错 → 缺依据/变形错误 |
| ③ 应用匹配 | 配对/单选（现实问题 ↔ 公式） | 匹配全对 | 错 → 缺动机（不会选工具）→ 补救推 step_type=8 工具选择训练 |

- 组题来源：`question.formula_id` 指定题 + AI 生成补充（走 E1 L-AI 层审核）；
- 全部进错题本、每日一练候选、能力画像。
