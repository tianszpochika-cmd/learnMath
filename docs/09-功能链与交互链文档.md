## 第一部分：功能链（9 条端到端链路）

> 表述约定：**[角色]** 动作 → **[系统]** 处理 → 产出/回写。每链给出前置、正常步、数据回写、异常分支。

### L1 新用户冷启动链

**前置**：用户从未注册；官网/二维码/分享落地。
**目标**：10 分钟内完成“注册 → 定位 → 首个任务 → 首次正反馈”。

| # | 步骤 |
|---|------|
| 1 | [用户] 落地官网/分享页 → 点「开始学习」→ 跳转 Web/端内注册页 |
| 2 | [用户] 选渠道注册：账号密码 / 手机验证码 / 邮箱 / 微信（未配置渠道隐藏，01 U-01）；**必须勾选《用户协议》《隐私政策》**（未勾选不可提交，01 U-05；文本 = article type=legal） |
| 3 | [系统] 建号（user、积分初始、每日任务初始化）→ 签发双 token → 落 /user/home |
| 4 | [系统] **测评引导弹层**（D3）：推荐入学测评，两个出口 = 「开始测评」/「跳过」 |
| 4a | 开始 → L5 测评子链（答题→定级→画像报告） |
| 4b | 跳过 → [系统] 默认 level_no=1、按注册时段/渠道粗给起点（第 1 章知识点），**打标 `placement=pending`，首次练习后静默校准** |
| 5 | [系统] 生成首周计划（规则引擎；AI 开则 LLM 优化文案）→ 计划确认页（可改每日时长） |
| 6 | [用户] 确认 → 落首页，首日任务高亮 → 完成第 1 课时 + 随堂练 |
| 7 | [系统] 完成动效：进度环 +1、+积分、连续打卡开始、触发首徽章「第一步」 |
| 8 | [系统] 站内信欢迎 + 明日任务预告（通知默认开） |

**回写**：user、learning_plan/plan_task、progress、mastery、attempt*、check_in、point_transaction、user_achievement。
**异常分支**：验证码频控（1004/5003）；短信未配→隐藏手机渠道（3200）；微信未配→隐藏微信入口；测评中途退出→记录 draft，下次进入续答或提醒；注册同名冲突→2006。

### L2 日常课程学习链（P1）

**前置**：L1 完成（或任意已有账号）。

| # | 步骤 |
|---|------|
| 1 | [用户] 首页「今日任务」→ P1 任务卡 → 进入课时页 |
| 2 | [系统] 课时页 = 左内容（Markdown+LaTeX/视频）+ 右随堂练位；加载即 started，心跳 30s 上报 |
| 3 | [用户] 学习 → 点「标记完成」或做随堂练 |
| 4 | [用户] 随堂练作答（**逐题即时反馈**，D2-练习态）→ 正误+解析+关联知识点 |
| 5 | [系统] 完成条件判定（读完标记+练习达标阈值，配置化）→ lesson progress=完成 |
| 6 | [系统] 回写：progress、mastery（随堂练判分驱动）、stat_daily、P1 路径节点 sequential 解锁下一课 |
| 7 | [系统] 页尾「下一课时」推荐 + 本课掌握度变化提示 → 回 L2-1 循环 |

**回写**：progress（duration 心跳累计）、attempt*(mode=5 随堂)、mastery、user_path_progress(P1)、stat_daily。
**异常分支**：课时下架→3001 + 返回课程页；视频链接失效→播放器错误态+反馈入口；心跳断网→本地累计、恢复补报；随堂练未达标→提示“再看一遍重点”，**不阻塞标记完成**（配置可改强阻塞）。

### L3 训练-纠错-复习链（核心留存闭环）

**前置**：有可用题库；用户至少完成 1 次作答。

| # | 步骤 |
|---|------|
| 1 | [用户] 入口任选：自由练习 / 试卷 / 每日一练 / 错题重练 / 关卡 → 开 attempt |
| 2 | [系统] 抽题（知识点×难度×未做优先）→ 下发（作答态**不含答案**） |
| 3 | [用户] 逐题提交 → **练习 mode 即时判分反馈；考试 mode 仅存草稿与用时**（D2） |
| 4 | [系统] 判分（02 §5.4 归一化）→ 逐题回写 attempt_answer；答错 → **同步入 wrong_book**（记错因标签可选） |
| 5 | [用户] 交卷（考试 mode 触发确认弹窗）→ 全卷判分 → 成绩报告（得分/用时/知识点分布/归因） |
| 6 | [系统] 报告页错题区 toast「N 题已加入错题本」→ [加入重练] 按钮 |
| 7 | [系统] SRS：错题 next_due=明日；答对升间隔 1→3→7d；到期进 `lm:srs:due` → 次日每日一练出现 |
| 8 | [用户] 重练连续 2 次正确 → 系统标 mastered（或手动移出）；掌握度回升 → 图谱/阶梯同步变色 |

**回写**：attempt、attempt_answer、wrong_book、mastery、stat_daily、积分（mode 相应规则）、成就（百题等）。
**异常分支**：重复交卷→状态机幂等返回原报告；断网提交→本地草稿+重试队列；题目被删→attempt_answer 快照题面（一期存 JSON 快照字段）；解答题→is_correct=NULL 直到 self-assess（01 U-04）。

### L4 晋级循环链（P4 阶梯 + P6 闯关）

| # | 步骤 |
|---|------|
| 1 | [用户] 阶梯页选知识点行/难度格，或闯关页选关卡 → 进入（校验 unlock_rule，02 §5.3） |
| 2 | [系统] locked → 3311 + 展示差多少（“还差 2 题达 80%”/“前置 {node} 未达标”——**D4 练习锁死**） |
| 3 | [用户] 作答（组卷式，练习反馈态） |
| 4 | [系统] 阶梯判定：正确率≥80% 且题量≥minCount → 解锁下一难度，**晋级战**试卷入口点亮（P4-3） |
| 5 | [系统] 闯关判定：普通关按星规则（正确率/用时 1-3 星）；Boss 关 paper_pass → 星数入 stage_rank |
| 6 | [系统] 周结算（每周一 04:00）：周积分+总星 → 段位升降 → 站内信通知 |
| 7 | [用户] 排行榜/挑战赛页回看 → 积分奖励入账（挑战 record → point 事件，幂等） |

**回写**：mastery（判定源）、user_path_progress.star、stage_rank、challenge_record、point_transaction、成就（段位/满星）。
**异常分支**：挑战赛过期进入→3304 类业务码；榜单 Redis 丢失→stat_daily 兜底重建；同卷重复刷分→每日积分上限规则（config）。

### L5 自适应链（P3 测评-计划-调档）

| # | 步骤 |
|---|------|
| 1 | [用户] 测评入口（L1 引导 / 首页 / 计划页“重新定位”）→ 开始自适应测评 |
| 2 | [系统] 按 rule_json 起档出题 → 逐题判 → 升/降档（连对升、错 2 降）→ 达终止条件定档 |
| 3 | [系统] 产出报告：维度雷达（dims_json 映射知识点）、level、推荐起点、薄弱子域 |
| 4 | [用户] 点「生成计划」→ 选每日时长/目标 → [系统] AI 开：LLM 出计划 JSON（校验失败回落规则）|
| 5 | [用户] 日历确认/手动增删改任务 → 生效 |
| 6 | [系统] 执行追踪：完成打勾；**连 3 天达标 → 下周量+1 档；连 3 天未完成 → 插入先修复测+回退**（02 §5.6） |
| 7 | [系统] 每周复盘（周报）附带计划调整建议 → 用户一键应用/忽略 |

**回写**：assessment_record（定级）、learning_plan/plan_task、mastery（测评作答同样回写）、study_report。
**异常分支**：测评中途退出→draft 续答；AI 计划 3102→回落规则并在 UI 注明“已按标准方案生成”；全部跳过测评用户→首次练习 ≥10 题后静默校准 level（D3-4b）。

### L9 激励结算链（事件驱动）


## 第二部分：交互链（页面级点击流）

> 格式：入口 → 步骤（含即时反馈）→ 出口；⚠ = 异常/分支。对应 05 信息架构的路由。

### I1 首页学习流（日常主路径）

```
首页 / 
 └ 今日任务卡[高亮第一项] → 点「开始」
     └ /paths/course/:id 课时页
         ├ 左：内容滚动（每 30s 心跳；进度条跟随阅读位置）
         ├ 右：随堂练[逐题] → 提交 → ✅绿/❌红 + 解析抽屉 + 关联知识点chip(可跳图谱)
         └ 「标记完成」→ 完成弹层(进度环+1、+10积分、掌握度↑提示) → 「下一课时」
 ⚠ 随堂练不达标：黄条提示“再看重点”，完成按钮仍可用(配置可改)
 ⚠ 课时下架：3001 toast → 返回课程页     ⚠ 未登录：守卫 → /login?redirect=
```

### I2 考试作答流（考试 mode）＋练习流（练习 mode）

```
/paper/:attemptId 作答页
 ├ 顶：倒计时(0→自动交卷) + 交卷按钮
 ├ 中：题干(QuestionCard 三态) + 选项/填空/解答区
 │    练习mode：[提交本题] → 即时正误+解析（D2）
 │    考试mode：[下一题] 仅存草稿(sessionStorage)，不判分（D2）
 └ 底：答题卡(✅已答 ○未答 ⚑标记) 点击跳题
 「交卷」→ 确认弹窗(未答 N 题警示) → 判分中动效 → /report/attempt/:id
    ├ 得分环 + 知识点分布柱图 + 用时
    ├ 错题清单 toast「N 题入错题本」→ [加入重练] → /wrongbook
    └ [AI 归因] 有Key出文；无Key→规则归因文案(D 可降级)
 ⚠ 中途刷新：恢复卷面+草稿   ⚠ 断网：草稿保留+顶部离线横幅+重试
 ⚠ 重复提交：幂等返回原报告
```
