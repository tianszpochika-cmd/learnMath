## 关键业务逻辑审查

1. **作答与辅助**：Web/移动端只在服务端返回 `in_progress`、`revision`、`feedbackMode`、明确可编辑态后写草稿；本机草稿按用户、作答和题序隔离。交卷前冲刷草稿；版本冲突保留本机与服务端两份供比较。AI、解析与深钻入口受活跃作答标记收紧，最终权限仍由服务端强制执行。移动端未明确多选答案编码时阻断提交。
2. **内容发布与社区**：官网资源只取公开已发布投影；数学 HTML 只由 KaTeX 严格渲染生成。社区帖子数字/文本审核状态统一映射；待审帖仅作者可见，待审或已删除回复不展示。排行只接受明确匿名字段，缺失时显示统一匿名占位。
3. **回执与账户**：打卡 POST 与后续状态 GET 分别记录；状态复核失败时不声称未打卡，也不自动再提交。注销申请缺二次验证 DTO，发起入口禁用；冷静期撤销需要服务端状态回读。导出只显示服务端已接收申请，下载仍从站内通知领取。
4. **移动导航与通知**：`pages.json` 注册 41 个实际 Vue 页面及五个主 Tab。通知数字类型/已读值映射到界面；深链只允许帖子、课程和报告等已知端内路径，不接受任意 URL。
